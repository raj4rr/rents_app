join() Method in JavaScript

Joins all array elements into a single string separated by the specified delimiter.

Syntax: arrayName.join(param1)

Example:

<html>
<body>
<script language="javascript">
function join_a()
{
 var myArray = new Array('Aditya','Anil','Ashish');
 alert(myArray.join('>>'));
}
</script>
<button onclick="join_a()">ArrayJoin</button>
