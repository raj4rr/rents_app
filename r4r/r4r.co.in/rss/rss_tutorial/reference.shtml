Name DESCRIPTION
channel The channel element contains metadata describing the channel itself, including a title, brief description, and URL link to the described resource (the channel provider's home page, for instance).
descriptionA brief description of the channel's content, function, source,textinput field's
imageAn image to be associated with an HTML rendering of the channel. This image should be of a format supported by the majority of Web browsers.
itemWhile commonly a news headline, with RSS 1.0's modular extensibility, this can be just about anything: discussion posting, job listing, software patch - any object with a URI.
linkThe URL to which an HTML rendering of the channel title,image ,etc will link, commonly the parent site's home or news page.
name The text input field's (variable) name.
title A title for the text input field . for eg r4r
url The URL of the image to used in the "src" attribute of the channel's image tag when rendered as HTML.
ratingThe PICS rating of the feed
ttlSpecifies the number of minutes the feed can stay cached before refreshing it from the source.
managingEditorIt is used to specify an e-mail address for the editor of the content of the feed
