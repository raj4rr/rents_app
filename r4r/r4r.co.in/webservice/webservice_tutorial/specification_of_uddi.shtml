UDDI was designed to provide a simple mechanism to support the discovery of Web services and their specifications. The Universal Description, Discovery, and Integration (UDDI) specification defines a SOAP-based Web service for locating WSDL. UDDI is a project that was founded by Microsoft, IBM.

Current version now being used is UDDI Version 2.0. UDDI specification involve metadata. A rich set of metadata can be associated with UDDI specification. Universal Description, Discovery, and Integration (UDDI) Specification involves the following:

Versions of UDDI

UDDI version 1: It includes UDDI Data Structure v1.0 and UDDI Programmer's API 1.0.

UDDI version 2: This version includes UDDI Version 2.0 Data Structure, UDDI Version 2.0 Replication, UDDI Version 2.0 Operator's.

UDDI Operator

This specification defines data management requirements.

UDDI Data Structure

This specification specifics the XML structures that are contained within the SOAP messages. These SOAP messages are defined within the UDDI API.
