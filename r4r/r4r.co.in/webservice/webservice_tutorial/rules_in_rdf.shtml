RDF rules define resources and statements.

Resources

RDF resources defines a resource to identify a property. RDF resources is a class of all resources. The resources with properties and property values.

AResourceis anything that can have a URI. such as "http://www.indo.org/web".

APropertyis a Resource that has name. e.g. is "writer" or "homepage".

AProperty valueis the value of a Property. e.g. is "http://www.indo.org".

Statements

rdf:Statementis an instance ofrdfs:Class. The combination of a Resource, a Property, and a Property value forms aStatement. The statement consists of predicate, subject, object.according to the subject of the statement will be: 

http://www.indo.org/web
The predicate is:writer
The object is: http://www.indo.org
