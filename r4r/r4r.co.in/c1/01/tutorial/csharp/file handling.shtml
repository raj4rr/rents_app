File Handling in C#

File handling is an unmanaged resource in your application system.This means that it is not handled by CLR.

The System.IO namespace includes various classes for file handling. File Handling It is used to read from and write to any location within a file.

  1. BinaryReader- It is used to read primitive data types from a binary stream.
  2. BinaryWriter- It is used to write primitive data types in binary format.
  3. StreamReader- It is used to read characters from a byte Stream.
  4. StreamWriter- It is used to write characters to a stream.
  5. StringReader- It is used to read from a string buffer.
  6. StringWriter- It is used to write into a string buffer.
  7. DirectoryInfo- It is used to perform operations on directories.
  8. FileInfo- It is used to perform operations on files.
Working With Files

The Directory Info object can also return a collection of all the files in each subdirectory found.

The GetFiles( ) methodreturns an array of File Info objects, each of which describes a file in that directory.

The File Info and File objects relate to one another, much as Directory Info and Directory do. Like the methods of Directory, all the File methods are static; like Directory Info, all the methods of File Info are instance methods.

  1. AppendText()- Creates a Stream Writer that appends text to the specified file.
  2. Copy()- Copies an existing file to a new file.
  3. Create()-Creates a file in the specified path.
  4. CreateText()- Creates a Stream Writer that writes a new text file to the specified file.
  5. Delete()- Deletes the specified file.
  6. Exists()- Returns true if the specified file exists.
  7. GetAttributes() and SetAttributes()- Gets and sets the File Attributes of the specified file.
  8. GetCreationTime() and SetCreationtime()- Returns and sets the creation date and time of the file.

StreamReader and StreamWriter classes

StreamReader and StreamWriter are concrete classes that derive from TextReader and TextWriter, respectively, and operate on a Stream (passedas a constructor parameter).

These classes allow you to combine a Stream (which can have a backing store but only knows about raw data) with a TextReader/TextWriter which knows about character data, but doesn't have a backing store.

Streams and Backing Stores

A stream represents the flow of data coming in and out of a backing store. A backing store represents the endpoint of a stream.

Abstract Stream class

Stream is an abstract class that defines operations for reading and writing a stream of raw, type less data as bytes. Once a stream has been opened, it stays open and can be read from or written to until the stream is flushed and closed.
