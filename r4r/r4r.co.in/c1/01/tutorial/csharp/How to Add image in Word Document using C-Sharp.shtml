How to Add image in Word Document using C#
Previous Home Next
  1. Create a new windows application project and add a button to it.
  2. On click of that button, we will open a document and insert a picture to it.
  3. (In the doc file insert a table at the location where you want the picture to appear.)
  4. Than add reference to (Word 10.0 or 11.0 object library) within COM tab of Add reference dialog box.
  5. After adding reference, add this directive
using Microsoft.Office.Interop.Word
