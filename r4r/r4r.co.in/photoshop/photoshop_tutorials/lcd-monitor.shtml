In this example I am going to teach you how to draw a LCD monitor by my this example, it has all the steps that use to draw a LCD monitor so follow now.

Step 1: Take a new file with any background color as you like, select ellipse tool and draw a as I have done here.

Step 2: Give shadow effect, go to layer menu -> layer style -> Drop shadow and make settings as given here.

Step 3: Give gradient effect, go to layer menu -> layer style -> gradient overlay and make same gradient effect as here.

Step 4: Give stroke effect, go to layer menu -> layer style -> stroke and make same settings.

You should have this picture.

Step 5: Select Rectangle tool (U key) and draw on the shape with black color.

Step 6: Select Pen tool (P key) and make a new anchor point in the bottom middle of the rectangle shape then set anchor point at this position.

You picture should be same.

Step 7: Select Rounded rectangle tool (U key) and draw with black color as here.

Step 8: Now select Rectangle tool (U key) and draw with any color, I have done it with white color.

Step 9: Give gradient effect, go to layer menu -> layer style -> gradient overlay and make color settings.

Step 10: Now select Ellipse tool (U key) draw like button with white color.
