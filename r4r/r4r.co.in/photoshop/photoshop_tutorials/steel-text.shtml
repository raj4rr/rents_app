In this example you will learn how to give a steel tool to the text, this can be possible by my this example so follow every step carefully to make same as I have done here.

Step 1: Take a new file with any background. select Text tool (T key) and write any text on the document with any color as you like

Step 2: Give gradient effect, this section is very important to give steel look. Go to layer menu -> layer style -> Gradient overlay and make same settings as given below.

Step 3: Give stroke effect, go to layer menu -> layer style -> stroke and use same color and settings.

The steel text is completed.
