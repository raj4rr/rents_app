This tutorial is going to teach you to draw a gun bullet, I have used a simple method to make it easily so don't waist time follow now.

Step 1: Take any size file as you need and select Rounded rectangle tool (U key) and draw a shape on the file as here.

Step 2: Use gradient effect to the bullet, go to layer menu -> layer style -> Gradient overlay and make same settings of the color.

The picture would as here.

Step 3: Use same step to make two more shape by same tool as I have done here.

Step 4: Select Pen tool (P key) and make anchor point then adjust to make both shape as here..

Your bullet picture is completed.
