In this example, I have try to draw a screw by using some steps, I hope you enjoy and lean it completely so follow all the steps to make same screw graphic.

Step 1: Take any size of file as you like, select Elliptical marquee tool (M key) and draw a circle as here.

Step 2: Select Rectangular marquee tool (M key) and hold Alt key then make cutting the selection by the mouse.

Step 3: Now fill any color as you like, I have filled here black color.

Step 4: Give gradient and stroke effect, go to layer menu -> layer style -> Gradient Overlay make same setting as given here.

Step 5: Give stroke effect, go to layer menu -> layer style -> Stroke and make same setting.

You picture should be same.

Step 6: Select Rectangular Marquee tool (M key) and make selection and fill color.

Step 7: Give gradient effect, go to layer menu -> layer style -> Gradient Overlay and make same settings.

The picture should be same.

Step 8: Draw a little shape and adjust with the gradient as done up.

Step 9: Make duplicate and set as here.

Step 10: Use same to make more and set, the screw graphic is completed.
