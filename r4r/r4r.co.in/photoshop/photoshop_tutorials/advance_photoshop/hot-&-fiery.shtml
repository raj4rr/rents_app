Hot and Fiery Effect
Previous Home Next

In this example I am going to make hot and fiery effect on the photograph, this effect is just like a person is standing around the fire. Let's star learning.

Step 1: Take any person picture, I have a beautiful lady picture to modify.

Step 2: Make color effect, go to Image menu -> Adjustment -> Hue/Saturation and set values as here.

The picture will look like this.

Step 3: Make duplicate layer and set blending mode as here.

Step 4: Now make again duplicate layer set blending mode "Normal" to "Soft Light". as given below.

Step 5: Take a new layer and fill any color as you like then go to Layer menu -> layer style -> gradient overlay and make color settings.

Step 6: Now change the gradient layer blending mode "Normal" to "Overlay".
