In this example I will teach you how to write a dark text on the dark background, I have taken a black background picture to write dark text on. Follow all the steps to make same as here.

Step 1: Take any new file with any dark color background, I have a black background file here.

Step 2: Now select Text tool (T key) and make settings, as given here. Write any text on the file as you like.

Step 3: Give a bevel and emboss effect, go to layer menu -> layer style -> Bevel and Emboss and make same settings.

Step 4: Now give stroke effect to the text, go to layer menu -> layer style -> Stroke and make same settings.
