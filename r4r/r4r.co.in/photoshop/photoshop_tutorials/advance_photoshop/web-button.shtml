In this example you will learn how to design a web button for use in the web. if you make you own web button, you should follow all the steps as given in this example.

Step 1: Take a new file with any size and select Rounded Rectangle shape (U key) and draw with any color as given here.

Step 2: Give gradient effect to the shape, go to layer menu -> layer style -> Gradient Overlay effect and set vales and color as given here.

Step 3: Now give stroke effect, go to layer menu -> layer style -> stroke and make settings as given here.

The picture should be same as here.

Step 4: Now draw same shape inside the Rounded rectangle shape with any color.

Step 5: Give gradient effect in the inside the Rounded rectangle shape, go to layer menu -> layer style -> Gradient overlay and make settings.

Step 6: Now give stroke effect using same path of the gradient effect as up.

The picture should be same.

Make duplicate layer and set as here and make web menu.
