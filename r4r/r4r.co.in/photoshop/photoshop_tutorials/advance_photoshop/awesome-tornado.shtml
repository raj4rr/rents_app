In this example I will teach you how to draw a awesome tornado effect on the project, all the step are important so follow this example without miss any step you would be make same effect.

Step 1: Take a new layer and fill any color as you like then select Gradient tool (G key) and set gradient as given here.

Step 2: Now Drag and drop by the mouse on the document as looking here.

Step 3: Now give ocean ripple effect, go to Filter menu -> Distort -> Ocean Ripple and set values.

Step 4: Give Radial Blur effect, go to Filter menu -> Blur -> Radial blur and set right angle as here.

Step 5: Make duplicate layer and give blur effect, go to Filter menu -> Blur -> Gaussian blur and set radius then change blending mode as given below.

Step 6: Make color balance, go to Image menu -> Adjustment -> Color balance and set values as here.
