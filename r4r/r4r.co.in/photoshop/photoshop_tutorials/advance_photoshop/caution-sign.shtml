In this example you are going to lean a simple way to draw a Caution Sign to show message, we use this type of sign to give a message to the user.

Step 1: First take a new file with any size as you need.

Step 2: Choose Pen tool to make Caution Sign shape, make anchor point with yellow color as here.

Step 3: Use gradient effect, go to layer menu > layer style > gradient overlay and make same settings.

Step 4: Use bevel and emboss effect, go to layer menu > layer style > Bevel and Emboss and set same settings.

Step 5: Give stroke effect, go to layer menu > layer style > stroke and make settings as here.

Step 6: Now draw a exclamation sign, select Custom shape tool (U key) and draw on as I have done here.
