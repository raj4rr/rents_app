Fire Effect

In this example I will teach you how to draw a fire effect, by this tutorial you can add fire on any places so follow this example to learn.

Step 1: First set foreground and background color as given here.

Step 2: Take a new layer and fill foreground color.

Step 3: Now add some fiery clouds, to Filter menu -> Render -> Clouds, press Ctrl + F four time and the picture will look like this.

Step 4: Make round effect, go to Filter menu -> Distort -> Polar Coordinates and select same point as here.

The picture should be same.

Step 5: Now set brightness and contrast, go to Image menu -> Adjustment -> Brightness/Contrast and set values as given here.
