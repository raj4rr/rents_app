Fumes Text
Previous Home Next

In this example you will learn how to make a fumes text effect, I have taken some simple step to make that. You have to follow all the step to make this effect yourself.

Step 1: Select foreground and background color and take a new file  with any size as you need.

Step 2: Add some fumes on the file, go to Filter menu -> Render -> Clouds, the picture should be same.

Step 3: Now make sharp fumes effect, press Ctrl + F till this picture. The fumes background will be completed.

Step 4: Take a new file with any size and select Text tool (T key) and write any text with any color as here.

Step 5: Make selection of the text, Click on the text layer with hold Ctrl key.

Step 6: Now first make copy of the fumes background as done up and go to Edit menu -> Paste Into (Ctrl + Shift + V), the text will look like this.

Step 7: Give bevel and emboss effect, go to layer menu -> layer style -> Bevel and Emboss and make settings as given here.

Step 8: Give Color Overlay effect, go to layer menu -> layer style -> Color overlay and select color.

The text will look like this.

Step 9: Now change blending mode of the layer "Normal" to "Linear Dodge" as here.

The text should be same.

Step 10: Take a new layer and fill blue color then change blending mode of the layer "Normal" to Overlay as given here.

Final fumes text effect
