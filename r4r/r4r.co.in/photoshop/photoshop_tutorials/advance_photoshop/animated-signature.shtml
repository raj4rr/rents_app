Animated Signature
Previous Home Next

In this example you will learn how to make an animated text signature. I am using a word to make animate like doing signature, you can use any word as you like.

Step 1: Select Text tool (T key) and make formatting of the text as given here.

Step 2: Now type first alphabet of the word as here.

Step 3: Take a new layer and type another alphabet of the word as I have done here.

Step 4: Use same upper step to write all the alphabet of the word on new layer.

Step 5: It is time to make animation, go to Window menu and select animation and in the first frame show only first alphabet layer. Take a new frame and show second alphabet and change time setting, use same step to complete all the alphabet layer on the separate layer as given here.

The animation window should be same as here.

This is your final signature picture.
