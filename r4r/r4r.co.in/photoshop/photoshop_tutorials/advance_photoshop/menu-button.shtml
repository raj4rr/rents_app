In this example you will learn how to draw a web menu button for use in the web, this button can be used in any website. Follow this example to make your own web button.

Step 1: Take a new file with any size and select Rounded rectangle tool (U key) then draw on the file with any color as here.

Step 2: Give gradient effect, go to layer menu -> layer style -> gradient overlay and make settings as given here.

Step 3: Now give stroke effect, go to layer menu -> layer style -> Stroke and set values as here.

Step 4: Select Line tool (U key) and draw line on the button with same stroke color as done up.

Step 5: Take a arrow symbol, select custom shape tool (U key) and choose arrow then draw on the button Red color.

Step 6: Now give bevel and emboss effect, go to layer menu -> layer style -> Bevel and Emboss and make settings as here.
