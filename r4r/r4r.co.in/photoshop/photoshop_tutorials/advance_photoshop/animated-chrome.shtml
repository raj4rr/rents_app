Animated Chrome Background
Previous Home Next

In this example you will learn how to make animate a chrome background, first draw chrome background and then go to animate. Follow all the step of the this example.

Step 1: Take a new layer and fill white color then go to Filter menu -> Noise -> Add noise and set value.

Step 2: Give chrome effect, go to Filter menu -> Sketch -> Chrome and set value.

Step 3: Make color balance, go to Image menu -> Adjustment -> Color Balance and set values as given here.

Step 4: Now make duplicate noise layer as done up then go to same path to give chrome effect settings as here.

Step 5: Now set chrome frame on the separate frame as here.
