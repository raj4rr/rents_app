In this example I will teach you how to make a chrome background I am using some filter effect for this example, start learning this tutorial to make yourself.

Step 1: First set foreground and background color, and fill foreground color by paint bucket tool as given below.

Step 2: Add noise, go to Filter menu > Noise > Add noise and settings as here.

Step 3: Now give chrome effect, go to Filter menu > Sketch > Chrome and make settings.

Step 4: Now make duplicate layer and change blending mode as given here.

Step 5: Make color balance, go to Image menu > Adjustment > Color Balance and set values as given here.
