In this tutorial I will teach you how to make a dark picture effect, you can use this technique to make picture for the horror effect. Follow this example to learn completely.

Step 1: Take a new picture to make this effect, I have selected a beautify lady picture.

Step 2: Change color settings, go to Image menu -> Adjustment -> Hue/Saturation and make settings as given here.

Step 3: Increase contrast, go to Image menu -> Adjustment -> Brightness/Contrast and set values as here.

Step 4: Now go to Image menu -> Adjustment -> Exposure and make settings as given here.

Step 5: Make color balance, go to Image menu -> Adjustment -> Color balance and set values as here.
