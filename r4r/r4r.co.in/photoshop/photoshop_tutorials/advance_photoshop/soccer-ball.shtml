In this example I will teach you how to draw a soccer ball, I am using some simple steps that are easy to understand. Follow every step to make same soccer ball as I have done here.

Step 1: Take a new file and select Ellipse tool (U key) with any color and draw a circle shape on the document.

Step 2: Give gradient effect, go to Layer menu -> layer style -> gradient overlay and make color settings as given here.

Step 3: Give bevel and emboss effect, go to layer menu -> layer style -> bevel and emboss and make settings as given here.

Step 4: Now give stroke effect, go to layer menu -> layer style -> Stroke and make settings.

The picture should be same.

Step 5: Take a Pen tool (P key) and draw polygonal shape as given here.

Step 6: Draw more shape by using upper tool and adjust the as here.

Step 7: Now link all the shape each other with the line, select brush tool and draw line with black color.
