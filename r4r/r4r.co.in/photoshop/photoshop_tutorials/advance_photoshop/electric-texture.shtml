This tutorial will teach you how to make a lighting effect in the sky in the rainy season, surely you will learn and enjoy this example so let's start.

Step 1: First set foreground and background color as I have done here.

Step 2: Take a new file and fill foreground color as here.

Step 3: Show sky, go to Filter menu -> Render -> Clouds and press four time Ctrl + F key to make this effect,

Step 4: Make duplicate layer and change blending mode of the layer as given here.

Step 5: Now increase color status of the picture, go to Image menu -> Adjustment -> Carve and make settings of the graph.
