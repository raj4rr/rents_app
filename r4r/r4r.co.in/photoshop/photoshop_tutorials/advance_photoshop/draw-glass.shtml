This example will teach you how to draw a glass effect, every steps of the example is very important to make this effect so follow with careful and don't miss step.

Step 1: Take a new file with any size as you need and select Pen tool (P key) and draw a glass shape with "#404143" color as given below.

Step 2: Give gradient overlay effect, go to layer menu -> layer style -> Gradient overlay and set color and values.

The picture will be look like this.

Step 3: Make a Circle shape on top of the glass with "404143" color and reduce opacity of the layer as given below.

Step 4: Select foreground color Black and draw line bottom of the glass with Brush tool (B key) as here.

Step 5: Give Gaussian blur effect, go to Filter menu > Blur > Gaussian blur and set radius as here.
