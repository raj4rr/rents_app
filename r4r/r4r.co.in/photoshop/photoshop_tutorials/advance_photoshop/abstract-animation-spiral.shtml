Abstract Animation Spiral

In this example you will lean how to make an abstract animation spiral effect, this animation example so follow with carefully the steps as given in this example.

Step 1: Take a new file with any size as you need with black background.

Step 2: Select Brush tool (B key) and press F5 then change brush format as given here.

Step 3: Now draw with blue color on the file as here.

Step 4: Make duplicate layer and press Ctrl + T key and right click then make selection as here.

Step 5: Now give twirl effect, go to Filter menu -> Twirl -> and set angle as here.

The picture will look like this.

Step 6: Give noise effect, go to Filter menu -> Noise -> Add Noise and set value as here.

Step 7: Now make duplicate layer and press Ctrl + T key the set at this position.

Step 8: Use same step to make many copy and set them like this.

Step 9: Go to Window menu > Animation and set all every layer on the separate frame as given here

Save file (Ctrl +Shift +S), your animation picture will be completed.
