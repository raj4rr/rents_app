In this example you will learn how to make a 3D text effect by the different way, this is very simple you need not follow more steps because I have done it with some steps so follow now.

Step 1: Take any background picture and gradient as you need.

Step 2: Select Text tool (T key) and set format then write text on the document with any color as given below.

Step 3: Make drop shadow effect, go to layer menu > layer style > Drop Shadow and set values as give here.

Step 4: Now give bevel and emboss effect, go to layer menu > layer style > bevel and emboss and make settings.

Step 5: Give a different color to text, I am given here a blue color on the text it can done follow upper layer path.
