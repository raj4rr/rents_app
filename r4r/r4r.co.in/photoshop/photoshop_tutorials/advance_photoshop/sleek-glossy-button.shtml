Sleek glossy Button

This example you will teach you how to draw a sleek glossy button for use in the web, follow this example to make this effect yourself for your own web.

Step 1: Take a new layer and draw a rectangle shape with black color as here.

Step 2: Give gradient effect, go to layer menu -> layer style -> gradient overlay and set color as given here.

Step 3: Now give stroke effect, go to layer menu -> layer style -> stroke and make settings.

The button will look like this.

Step 4: Make circle selection by the Elliptical Marquee tool (M key) and cut the selection size by Alt + mouse.

Step 5: Take a new layer and fill white color and change blending mode as given here.

The button will look like this.

Step 6: Make duplicate and set them like here that is the web menu bar.
