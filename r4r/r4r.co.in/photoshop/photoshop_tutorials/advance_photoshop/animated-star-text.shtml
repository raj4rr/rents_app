Animated Shining Star
Previous Home Next

In this example you will learn how to make animated shining star effect on the any text picture, first we you have to make a text effect to apply star effect on.

Step 1: Take a black background color picture and select Text tool (T key) and type text on the document with blue color as here.

Step 2: Give bevel and emboss effect, go to layer menu -> layer style -> bevel and emboss and make settings as here.

Step 3: Give Inner glow effect, go to layer menu -> layer style -> inner glow and make settings as given here.

Step 4: Select Polygonal lasso tool (L key) and make selection like star then take a new layer and fill white color.

Step 5: Make duplicate layer and modify the size and set them like a star as given here.

Step 6: Select all the star layer and merge then make duplicate layer and reduce size as here.

Step 7: Now give blur effect, go to Filter menu -> Blur -> Gaussian blur and set radius.

Step 8: Make duplicate both star layer and put them different place.

Step 9: Now make animation, go to Window menu -> Animation and set a little star on the first frame then set big star layer on the second frame. Use same steps set another stars as given here.
