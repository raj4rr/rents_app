Dirty Text Effect
Previous Home Next

In this example you will learn how to make a dirty text effect, follow some simple steps as given in this example to make this effect yourself. I am sure you will done same.

Step 1: Take any background picture and type text as you like with text tool. with black color as I have done here.

Step 2: Now add clouds effect, go to Filter menu -> Render -> Cloud, the text should be same.

Step 3: Make selection of the text and give noise effect, go to Filter menu -> Noise -> Add Noise and set values as here.

Step 4: Give bevel and emboss effect, go to Layer menu -> Layer style -> Bevel and Emboss and set values.

Step 5: Give Inner glow effect, go to Layer menu -> Layer style -> Inner glow and make settings as given here.

The text should be same.

Step 6: Select Brush tool (B key) and choose brush type then take a new layer and apply on the text area with black color as given here.

Step 7: Now change blending mode of the layer "Normal" to "Soft Light" as here.

Step 8: Change Foreground color and take a new layer then fill color by the paint bucket tool (G key).

Step 9: Now change blending mode of the layer "Normal" to "Color Burn".

Final dirty text effect
