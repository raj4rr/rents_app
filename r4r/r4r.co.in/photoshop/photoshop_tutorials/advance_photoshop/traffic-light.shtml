Traffic Light

In this example, you will learn how to draw a graphic traffic light for your project, some simple step are used to make this traffic light. follow all the steps to make completely.

Step 1: Take a new file and select Rounded Rectangle tool (U key) and draw like a pipe with any color and use gradient effect as given here.

Step 2: Select Rectangle tool (U key) and draw with black color.

Step 3: Give bevel and emboss effect, go to layer menu -> layer style -> bevel and emboss and make settings.

Step 4: Now make copy and set as given here.

Step 5: Make circle, select ellipse tool (U key) and draw a circle with Red color.

Step 6: Now give bevel and emboss effect, go to layer menu -> layer style -> bevel and emboss and make settings.

Use same steps to make another two light with different color.
