In this example I will teach  you how to make a film photo effect, for this effect you need a photo to make this effect, I have selected a road photograph to modify lets start how it made.

Step 1: Take any picture to modify as here.

Step 2: Make settings of the level, go to Image menu ->Adjustment -> Level and make settings.

Step 3: Now set color settings, go to Image menu -> Adjustment -> Hue/Saturation and make color settings as here.

Step 4: Go to Image menu -> Adjustment -> Brightness and contrast and make settings.

The picture should be same.

Step 5: Make duplicate layer and give blur effect, go to Filter menu -> Blur -> Gaussian blur and set radius as here.

Step 6: Select Eraser tool (E key) and modify setting then move in the middle of the picture as given here.

Step 7: Hide all the layer rest both picture layer right click on the layer se choose "Merge Visible".

Step 8: Set again hue and saturation effect, go to Image menu -> Adjustment -> Hue/Saturation and make settings.

Step 9: Increase color glow, go to Image menu -> Adjustment -> Carves and make setting as given below.

Step 10: Now add thick black line on the top and bottom of the picture, make selection and take a new layer then fill black color by the paint bucket tool.

Step 11: Use same step to make another thick black line.
