Brick text effect

In this example you will learn how to make brick text effect, some simple steps are used to make this text effect. Follow to know how is it done by this example.

Step 1: Take text tool (T key) and make formatting and type text on the document as given below.

Step 2: Give texturizer effect, go to Filter menu > Texture > Texturizer and set values as here.

The picture should be same.

Step 3: Give bevel and emboss effect, go to Layer menu > layer style > bevel and emboss and make settings.

Step 4: Now give Inner glow effect, go to layer menu > layer style > inner glow and make settings.

Final text effect.
