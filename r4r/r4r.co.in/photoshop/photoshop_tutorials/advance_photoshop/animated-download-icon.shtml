Animated Download Icon
Previous Home Next

In this example you will learn how to make an animated download icon, It is an animated icon tutorial so follow all the step and draw your own an animated download icon.

Step 1: Make selection by the Pen tool (P key) our Polygonal lasso tool (L key) as here.

Step 2: Take a new layer and fill black color in the selection by the Paint Bucket tool (G key).

Step 3: Select Dodge tool (O key) and apply on the band of the figure as here.

Step 4: Select Pen tool (P key) and draw a rectangle shape with "#747373" color.

Step 5: Now draw again rectangle shape in the the box with "#9d9d9d" color.

Step 6: Select Custom shape tool (U key) and choose arrow then draw on the box with Green color as here.

Step 7: Give Drop shadow effect, go to layer menu -> layer style -> Drop shadow and make settings.

Step 8: Give stroke effect, go to layer menu -> layer style -> stroke and set values.

The picture will look like this.

Step 9: Now make duplicate layer of the arrow as here.

Step 10: Go to Window menu -> animation -> and set arrow layer on the separate frame in the animation window as here.

Step 11: Save file (Alt +Ctrl +Shift + S)
