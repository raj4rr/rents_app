This tutorial will teach you how to make a animated gradient rays text effect, I am using only gradient effect to make this animation follow this tutorial and enjoy animation.

Step 1: Select Text tool (T key) and type text on the document with any color as you like.

Step 2: Give stroke effect, go to layer menu -> layer style -> Stroke and set value and color.

Step 3: Give gradient overlay effect, go to layer menu -> layer style -> Gradient overlay and set color as given here.

The will look like this.

Step 4: Now make duplicate layer and change its gradient color settings as the text looking below.

Use same step to make copy text and change them gradient four time, the gradient settings given below.

Step 5: Now open animation frame to make animate the text, go to window menu -> animation and set all the different text on the separate frame as given here.
