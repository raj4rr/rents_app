In this example you will learn how to make material rendering effect, I have used Photoshop filter to make this effect. Follow this example and learn yourself.

Step 1: Take any background picture, I have taken a gradient background picture.

Step 2: Select Ellipse tool (U key) and draw on the document with white color as here.

Step 3: Select Burn tool (O key) and apply on the circle with this setting as given below.

Step 4: Select foreground color and apply on the circle with the Dodge tool (O key) as here.

Step 5: Give Bas Relief effect, go to Filter menu -> Sketch -> Bas Relief and set values as given here.

Step 6: Make duplicate layer and change blending mode as given here.

Step 7: Draw Circle shape bottom to make shadow effect
