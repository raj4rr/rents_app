Neon glow text effect

This tutorial will teach you a different way to make a Neon glow text effect, I have tried here to make this effect to learn a another technique to make this effect.

Step 1: Take a black background file and select Text tool (T key) and type text with white color.

Step 2: Hold Ctrl key and mouse click on the text layer to make selection of the text as here.

Step 3: Now convert Selection into the line, Take a new layer with selection and got Edit menu -> Stroke and make settings as here.

The text layer look like this.

Step 4: Give blur effect, go to Filter menu -> Blur -> Gaussian blur and set radius as here.

Step 5: Give wind effect, to Filter menu -> Stylize -> Wind and make settings.

Step 6: Make duplicate layer and modify layer blending mode as I have done here.
