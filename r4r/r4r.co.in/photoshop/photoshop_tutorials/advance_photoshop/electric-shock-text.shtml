Electric Shock Text
Previous Home Next

This example will teach you how to make a electric shock text effect, follow every step carefully to learn completely. I am sure you can also make same as I have.

Step 1: Take a new file with black background and select text tool (T key) and write any text on the file with white color as here.

Step 2: Select text and press Ctrl + T and right click then make selection as here.

Step 3: Add some lines, go to Filter menu -> Stylize -> Wind and make settings as here.

The text should be same.

Step 4: Add some more line right site of the text, go to Filter menu -> Stylize -> Wind and make setting as given here.

Step 5: Now change the position of the text as on first text layer, the text should be same.

Step 6: Take a new layer and choose blue color then fill color by the paint bucket tool as here.

Step 7: Now change blending mode of the layer "Normal" to "Multiple".

Final Electric shock text effect
