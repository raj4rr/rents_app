This example I will tech you how to draw a web 2.0 menu bar for the web project, use this example and put a web 2.0 menu bar in any web site so start learning.

Step 1: Take a new file and draw a Rectangle shape with white color and dark stroke color as here.

Step 2: Draw again Rectangle shape with Red color inside as I have done here.

Step 3: Give Gradient effect, go to layer menu -> layer style -> Gradient Overlay and make settings.

Step 4: Make selection by the Rectangular Marquee tool (M key) and take a new layer then fill white color and change the blending mode as given here.

Step 5: Give Blur effect, go to Filter menu -> Blur -> Gaussian blur and set radius as here.

The picture will look like this.

Step 6: Select Line tool (U key) with dark color as stroke and draw on the figure as here.

Step 7: Make duplicate layer of the line layer and set them like this.

Step 8: Now write text as you want
