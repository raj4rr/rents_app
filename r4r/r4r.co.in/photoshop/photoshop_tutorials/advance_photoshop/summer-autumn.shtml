Summer leaf to Autumn leaf effect
Previous Home Next

In this example I will teach you how to convert a summer picture to autumn picture, I have selected a summer leaf picture to make this effect on, follow to make yourself this effect.

Step 1: Take a picture to make this effect, I have a green leaf picture to modify.

Step 2: Make color settings, go to Image menu -> Adjustment -> hue/saturation and set values as given here.

Step 3: Make color balance, go to Image menu -> Adjustment -> Color balance and set values.

Step 4: Now set color level, go to Image menu Adjustment -> Level and make settings as given below.

Step 5: Take wind tool and click on the some place to make selection as done here.

Step 6: Take a new layer and fill "#ef9302" color in the selection then change layer settings as given here.

The picture will look like this.

Step 7: Now go to Image menu -> Adjustment -> Corves and make up graph to increase color quality.
