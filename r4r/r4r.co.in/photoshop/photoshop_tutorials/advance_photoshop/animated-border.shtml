Animated Border Text

I am sure you will enjoy this example, it is an animation example. You will learn how to make animate any text border by using some simple steps as given in this tutorial.

Step 1: Take a new file and text tool (T key) and write text on the file with any color as you want.

Step 2: Hold Ctrl + mouse click on the text to make text selection then go to Select menu -> Modify -> Expand make settings.

Step 3: Take a new layer and fill black color as looking here.

Step 4: Give gradient overlay, go to Layer menu -> Layer style -> Gradient overlay and make settings of the color.

The will look like this.

Step 5: Make duplicate layer and change same gradient overlay angle as here.

Step 6: Use same step to make three more copy, change gradient angle in the round shape.

Step 7: Make animation, go to Window Menu -> Animation and set every border layer on separate frame.
