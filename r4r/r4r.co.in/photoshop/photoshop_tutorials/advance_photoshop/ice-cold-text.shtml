Ice Cool Text Effect
Previous Home Next

This tutorial will teach you how to make a Ice cool text effect, It has complete steps to make this type of text. Follow this example and learn completely.

Step 1: Take a new file with any color and background then select Text tool (T key) and type text on the document.

Step 2: Give Inner shadow effect, go to Layer menu -> layer style -> Inner shadow and make settings as here.

Step 3: Give Inner glow effect, go to Layer menu -> layer style -> Inner glow and make settings as given here.

Step 4: Now give bevel and emboss effect, go to layer menu -> layer style -> bevel and emboss and make settings.

Step 5: Give stroke effect, follow upper path and select stroke then make settings.
