Lighting Text Effect

This example will teach you how to make lighting effect in the text, follow all the step of this example to learn completely the technique to make this effect.

Step 1: Take a new file with black background and select Text tool (T key) and type text on the file.

Step 2: Make duplicate layer and press Ctrl + T and increase the text size as here.

Step 3: Hide small text layer then give wind effect, go to Filter menu -> Blur -> Radial blur and select option as here.

Step 4: Press Ctrl + F key four time, the picture will look like this.

Step 5: Now change the color, go to Image menu -> Adjustment -> Hue/Saturation and set values.

Step 6: Now unhide the small text layer as here.
