Glassy Menu Bar
Previous Home Next

In this example you will learn how to draw a glassy menu bar for the web, you can use it in your web project. Follow all the step to learn completely this technique.

Step 1: Take a new file with appropriate size and select Rounded rectangle tool (U key) and draw on the document as given here.

Step 2: Now give gradient effect, go to layer menu -> layer style -> gradient overlay and make setting of the color as here.

Step 3: Now give stroke effect, go to Layer menu -> layer style -> Stroke and make settings.

The Menu bar will look like this.

Step 4: Select Line tool (U key) with stroke color as done up and draw line in the bar as done here.

Step 5: Make duplicate layer of the line and set them to make segment for the button.

Step 6: Now write text in the segment, Take text tool (T key) and make formatting as given here then write text on.
