In this example I will teach you how make animated light, I have taken here a road light and going to make active slowly light. You need also a light to this effect on, so lets star.

Step 1: Take a light picture to make this effect. I have choose a road light for that.

Step 2: Make selection of the light area by the Polygonal lasso tool (L key) as looking here.

Step 3: Take a new layer and fill "#ed9c01" in the selection like this picture.

Step 4: Now change blending mode of the fill color layer "Normal" to "Color", the picture will look like this.

Step 5: Make duplicate layer and change blending mode "Normal" to "Vivid Light", the should be same.

Step 6: Set first color layer on the first frame and set second on the second frame then go to make animation, go to Window menu > Animation and select Tweens animation frame as given here.
