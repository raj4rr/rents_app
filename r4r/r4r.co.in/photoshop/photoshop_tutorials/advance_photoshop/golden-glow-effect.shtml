Golden Glow Effect
Previous Home Next

This example will teach you how to give a golden effect to any photograph with some simple steps so follow all the steps to learn completely and enjoy this example.

Step 1: Take any picture to modify, I have selected a beautiful girl as here.

Step 2: Make duplicate layer and go to Filter menu -> Blur -> Gaussian blur and make settings as given here.

Step 3: Make adjustment of the color, go to Image menu -> Adjustment -> Hue/Saturation and make settings.

Step 4: Now click on the master menu and select Reds option and set values as given here.

Step 5: Make color balance, go to Image menu -> Adjustment -> Color Balance and set values.
