This is very interesting example, in this example I have a stop fan picture to make running mode. It is very simple example to make this effect, follow all the steps and make yourself.

Step 1: Take a fan picture to make running effect as I have.

Step 2: Select Polygonal lasso tool and Pen tool to make selection of the fan blades as I have done here.

Step 3: Make copy of the fan blade as selected up and take new layer then past and adjust as here.

Step 4: Use same upper step to make many fan blades copy and set them like this picture.

Step 5: Now make animation frame, go to Window menu -> Animation and set your all the blades layer on separate frame as here.
