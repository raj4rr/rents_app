In this example you will learn how to give a many color effect on the picture, I am using a brave boy picture to make multiple photo color effect. Follow to learn this technique.

Step 2: Select color mode, select Gradient tool (G key) and select color.

Step 4: Change the gradient layer blending mode as here.
