Caramel Text

In this example your will surely enjoy because I am going to teach you how to make a caramel text effect. It has been done by some simple step so follow this example.

Step 1: Take a new file and select Text tool (T key) and make formatting then write text on the document as given below.

Step 2: Give gradient effect, go to Layer menu > Layer style > Gradient overlay and make color settings and values as given here.

Step 3: Give Bevel and Emboss effect to the text, go to layer menu > layer style > Bevel and emboss and make settings.

Step 4: Now Give final color overlay effect, go to layer menu > layer style > Color overlay and set value and color.
