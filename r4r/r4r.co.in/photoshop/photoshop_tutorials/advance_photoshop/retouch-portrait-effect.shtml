Retouch Portrait Effect
Previous Home Next

In this example I will teach you how to make a retouch portrait effect, I am going to make this effect on a beautiful lady picture. You can make this effect on any picture so follow now.

Step 1: Take any picture to modify, I have selected a beautiful lady picture.

Step 2: Make color adjustment, go to Image menu -> Adjustment and apply Auto Level, Auto Contrast and Auto Color.

Step 3: Modify level settings, go to Image menu -> Adjustment -> Level and make settings.

Step 4: Give Gaussian blur effect, go to Filter menu -> Blur -> Gaussian blur and set value as here.

Step 5: Make duplicate layer and change blending mode "Normal" to "Soft Light".

Step 6: Now change color settings, go to Image menu -> Adjustment -> Hue/Saturation and make settings.
