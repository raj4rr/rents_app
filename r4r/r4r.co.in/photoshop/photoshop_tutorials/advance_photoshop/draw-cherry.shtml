In this example you will learn a easy technique to draw a cherry, I have explained this example by some simple steps. I am sure you can also draw this by following all the steps.

Step 1: Take a new file with any size as you need then choose "#88281c" color and draw an apple shape with pen tool (P key).

Step 2: Make gradient effect, go to layer menu -> layer style -> gradient overlay and make same settings.

Step 3: Make bevel and emboss effect, go to layer menu -> layer style -> bevel and emboss and make settings.

Step 4: Make inner glow effect, go to layer menu -> layer style -> inner glow and make settings as given here.

Step 5: Select Pen tool (P key) and make point with yellow color as here.

Step 6: Make gradient effect, go to layer menu -> layer style -> gradient overlay and make settings.

Step 7: Make bevel and emboss effect, go to layer menu -> layer style -> bevel and emboss and make settings as given here.

Step 8: Now add noise go to Filter menu -> Noise -> Add noise, The picture should be like this.

Step 9: Make white spot on the object, select ellipse tool (U key) and draw with white spot.

Step 10: give blur effect, go to Filter menu -> Blur -> gaussian blur and set radius as here.
