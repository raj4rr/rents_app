Animated Digital Clock
Previous Home Next

This example will teach you how to draw a digital clock and animate the time, there are many step to make this effect so follow this example and learn yourself.

Step 1: Take a new file with any size and select Rounded shape tool (U key) and make settings then draw on the document.

Step 2: Now draw on the shape with Dodge tool and Burn tool as given here.

Step 3: Select Rectangle tool (U key) and draw wit black color as here.

Step 4: Give Gradient Overlay effect, go to layer menu -> layer style -> Gradient overlay and make color settings.

Step 5: Now draw a gain Rectangle shape with black color as here.

Ste 6: Give bevel and Emboss effect, go to layer menu -> layer style -> Bevel and Emboss and set values as here.

Step 7: Now draw button by the ellipse tool with red color.

Step 8: Give stroke effect, go to Layer menu -> layer style -> Stroke and set value.

Step 9: Make duplicate layer and set as here.

Step 10: Select Text tool (T key) and make formatting then write text on the black Rectangle, change Numeric value on the new layer like increasing second and minute like "58", "59".

Step 11: Now set the time numeric value layer like increasing time as here.
