Texture Text Effect

In this example you will see how to draw a texture text effect, there are many type of texture effect I am using on type of text of them to make this text effect.

Step 1: Select text tool (T key) and make formatting and type text on the document.

Step 2: Show noise effect, go to filter menu -> Noise -> Add noise and set values as given here.

Step 3: Go to Filter menu -> Brush Stokes -> Crosshatch and make settings.

Step 4: Go to Filter menu -> Artistic -> Film Grain and make settings.

Step 5: Now give bevel and emboss effect, go to Layer menu -> layer style -> Bevel and Emboss and make settings.

Step 6: Give Drop shadow effect, go to Layer menu -> layer style -> Drop shadow and make settings.
