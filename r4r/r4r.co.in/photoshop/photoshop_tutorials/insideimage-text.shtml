You have been seen many place in the news paper and magazine, image in the text. Be happy I am going to teach you how can make that use all the steps as given in this tutorials.

Step 1: Take any picture of the background where you write text on, I have taken a part of garden picture.

Step 2: Select Text Tool (T key) and modify the text formatting as you like then write text on the file as I have done here.

Step 3: Make Text path selection, hold Ctrl + mouse click on the text layer to make selection then hide the text layer.

Step 4: Now press Ctrl + Shift + I key to make inverse selection then press del key to delete selected area.

Whatever rest in the file that is you image inside text effect as here.
