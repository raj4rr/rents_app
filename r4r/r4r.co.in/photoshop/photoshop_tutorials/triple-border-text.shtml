Create Triple Border text
Previous Home Next

Your would have been make one border text easily by the Photoshop but in this tutorial you will learn about triple border text effect, it is so easy by this tutorial so follow now.

Step1: Take a new file to write text with any size as like then select Text tool (T key), write text on the file and give layer name "text layer".

Step 2: Make text selection, hold Ctrl + Click mouse on the text layer. You can see, your text is selected as here..

Step 3: Now you have to decrease the selection, go to Select menu -> Modify -> Contract and make same setting your text will be look like this.

Step 4: Now fill color in the selection as you like, take foreground color and fill by the paint bucket tool (G key) in the selection.

Step 5: Use second step to make text selection again then go to Select menu -> Modify -> Expand and make setting.

Step 6: Take a new layer under the text layer in the layer platters then fill blue color by the paint bucket tool (G key).

Step 7: Use stroke effect, go to Layer menu -> layer style -> Stroke and make same setting.
