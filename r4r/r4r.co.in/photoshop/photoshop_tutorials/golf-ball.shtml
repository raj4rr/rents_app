Make a Golf Ball
Previous Home Next

In this example, we are going to teach you how to draw a golf ball, we are using many steps those make it easy. I am sure you can also make golf boy by this example.

Step 1: Take a new file and draw black dot as I have done here.

Step 2: Blur effect, go to Filter menu -> Blur -> Gaussian Blur and set radius 1.0 px.

The should be same.

Step 3: Now go file menu -> Define Patterns and give any name as you like then go again file menu and select fill option.

You file should be same.

Step 4: Press Ctrl + T key and modify the position of the file as I have done here.

Step 5: Select Elliptical Marquee tool (M key) and draw a circle selection then press Ctrl + Shift +I to make inverse selection and press del key.

The picture should be same.

Step 6: give stroke effect, go to layer menu -> layer style -> stroke and make same settings as here.

Step 7: Take a new layer under the golf layer, select Gradient tool (G key) and make same settings then apply in the selection.

Step 8: Come to golf layer and set blending mode 'Normal' to 'Multiply', the picture should be same.

Step 9: Go to Filter menu -> Liquefy, set tool and brush size apply in the middle of the golf.

Step 10: Give light effect, go to Filter menu -> Render -> Lighting Effect and set as here.

Step 11: Take any type of background as here, the golf picture is completed.
