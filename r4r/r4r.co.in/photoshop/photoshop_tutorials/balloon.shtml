Follow this tutorial to learn how to draw a balloon in the Photoshop, this tutorial has some steps to make that easily. Try to make that as I have done here.

Step 1: Take a new file and select Ellipse tool (U key) with blue color then draw on the file as you have taken.

Step 2: Give gradient effect, go layer menu -> layer style -> gradient overlay and select same color and settings.

Step 3: Give stroke effect, go to layer menu -> layer style -> Stroke and make settings.

Step 4: Now give bevel effect, go to layer menu -> layer style -> Bevel and Emboss and make settings.

Step 5: At last give inner glow, go layer menu -> layer style -> inner glow make settings.

Step 6: Select Pen tool (P key) and make anchor point as here.

Step 7: Select brush tool with '1px' and take a new layer to draw a line with black color.

Step 8: Make duplicate layer and set that.
