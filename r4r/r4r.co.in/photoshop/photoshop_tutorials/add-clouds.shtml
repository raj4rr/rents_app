If get any picture which have no clouds, don't worry you can now add clouds on that by this tutorial. I have completed this effect only 4, 5 steps to follow now.

Step 1: Take any picture of the hose or any garden, I have taken here a beautiful house picture to modify.

Step 2: Select Polygonal lasso tool (L key) and make selection where you want to add clouds effect as here.

Step 3: Take a new layer and set background and foreground color as looking below.

Step 4: Add cloud effect, go to Filter menu -> Render -> Clouds, you see the cloud effect in the new layer then draw press Ctrl + T and adjust as here.

Step 5: Now come to selected layer as done in the 'step 2' and press Shift + I key to inverse selection and press del key.
