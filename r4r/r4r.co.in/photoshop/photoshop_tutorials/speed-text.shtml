In this example you will learn a running mode of the text, follow this example and give any text a speed text effect. I have used here very simple steps to make that.

Step 1: Take a new file with black background color as I have done here.

Step 2: Select text tool (T key) and write text with same formatting on the file as here.

Step 3: Make duplicate layer of the text and go to Filter menu -> Stylize -> Wind and make settings as here.

Step 4: Now give blur effect, go to Filter menu -> Blur -> Gaussian Blur and make setting.

You would be have this picture.

Step 5: Use color overlay effect, go to Layer menu -> Layer style -> Color overlay and use same color as here.
