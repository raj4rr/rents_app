Create Text on the Sand

In this example, I am going to teach you to how can write text on the sand in the Photoshop, this has been easy by this example so follow now.

Step 1: Take a sand picture to modify as I have taken here.

Step 2: Select Text tool (T key) and write text on the sand picture.

Step 3: Press Ctrl + T key and right click and apply as given here.

Step 4: After selection 'skew' option modify the position of the text according to photo.

Step 5: Stroke effect, go to layer menu -> layer style -> stroke and make settings as here.

The picture should be same as here.

Step 6: Now reduce the opacity of the layer '100%' to '35%'.
