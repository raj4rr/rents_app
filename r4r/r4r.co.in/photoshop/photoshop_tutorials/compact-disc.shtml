Make a Compact Disc

In this example, we will teach you a simple process to draw a compact disc by the Photoshop. we have tried to make it with some easy steps to learn easily so follow now.

Step 1: Open a new document with any size as you like and select Ellipse tool (U key) and draw a circle with any color.

Step 2: Give gradient effect, go to layer menu -> layer style -> gradient overlay and make settings of the color and position.

Step 3: Give glow effect, go to layer menu -> layer style -> Inner glow and make same settings.

Step 4: Give stroke effect, go to layer menu -> layer style -> stroke and make settings.

The picture should be as here.

Step 5: Make duplicate layer and press Ctrl + T key and decrease size then set in the middle of the circle and change color as here.

Step 6: Use same step to make another circle shape in the middle with white color.

Step 7: Give shadow effect, go to layer menu -> layer style -> drop shadow and set color and possition.
