Make a Chocolate Text
Previous Home Next

In this example, you are going to learn how to make a chocolate text effect, it has been easy by this example. I am sure you like it and enjoy.

Step 1: First take a new file with any size and any color of background then write text by the text tool (T key). You can also modification of the text format by the text property.

Step 2: lets adjust the different layer style, go to layer menu -> layer style -> Bevel and Emboss and make same setting as here.

Step 3: Now color Overlay settings, go to layer menu -> layer style -> Color Overlay and make same setting.

Step 4: Give stroke effect, go to layer menu -> layer style -> Stroke and make same setting.
