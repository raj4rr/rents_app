Make a Pen Drive

In this example I am going to teach you to draw a pen drive, you have to follow all the steps care fully to draw same pen drive as don in the example so let's star.

Step 1: Take a new file and select Rounded rectangle shape (U key) and draw with any color on the document.

Step 2: Give gradient effect, go to layer menu -> layer style -> gradient overlay and make settings of the color.

You should have this picture.

Step 3: Make duplicate layer and press Ctrl + T key and decrease size then set as here.

Step 4: Give gradient effect, go to layer menu -> layer style -> gradient overlay and make settings.

Step 5: Give stroke effect, go to layer menu -> layer style -> stroke and make settings.

Step 6: Now select Rectangle tool (U key) and draw top on the pen drive with same color as here.

Step 7: Give bevel effect, go to layer menu -> layer style -> bevel and emboss and make settings.

Step 8: Use same tool with black color to draw a little shapes that would be your final pen drive.
