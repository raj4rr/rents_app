Make a Ice Text Effect
Previous Home Next

In this example, you will learn how to make your text into an ice effect, use all the steps of the example to make same as I have completed this effect.

Step 1: First take a new file with any size and background color and select Text tool (T key) and make formatting as here.

Step 2: Now write text on the file as you like, I have written here my web site.

Step 3: Give glow effect, go to layer menu -> layer style -> Inner glow and make same settings.

Step 4: Give bevel and emboss effect, go to layer menu -> layer style -> Bevel and Emboss and make same settings.

Step 5: Set color, go to layer menu -> layer style -> Color overlay and make same settings.

Step 6: At last give stroke effect, go to layer menu -> layer style -> Stroke and make settings.

The ice text is completed
