Create Stone Text
Previous Home Next

Follow this example to lean how can give a stone effect to the text, you will lean it by this example. You have to learn every step carefully to make same here.

Step 1: Open a new document and set size as you like, select Text tool (T key) and write text on the document with stone color as here.

Step 2: choose a pattern, go to layer menu -> layer style -> Pattern Overlay and set pattern and another settings.

Step 3: Color effect, go to layer menu -> layer style -> color overlay and choose color as settings.

Step 4: Bevel effect, go to layer menu -> layer style -> Bevel and Emboss and make settings.

Step 5: Glow effect, go to layer menu -> layer style -> Inner glow and make settings as here.

The stone text is completed.
