Make Fog Effect

learn in this tutorial how to draw fog in the any picture, I have a agriculture picture to draw a fog on the picture, you can also draw buy using this example.

Step 1: Take any picture to modify as here.

Step 2: Make duplicate layer and go to Filter menu -> Blur -> Gaussian blur and set radius as here.

Step 3: Polygonal lasso tool (L key) and make selection in the middle of the picture.

Step 4: Select Foreground color '#f1eded' and take a new layer and fill this color in the selection by the Paint Bucket tool (G key).

Step 5: Give filter effect, go to Filter menu -> Blur -> Gaussian blur and set radius.

Step 6: Now reduce opacity of the layer '100%' to '73%'.
