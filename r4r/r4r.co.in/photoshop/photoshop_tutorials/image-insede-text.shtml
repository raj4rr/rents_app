Image Inside Text

In this example, you can learn how to put any type of image inside the text, I am sure you will learn and enjoy this tutorials.

Step 1: Take any picture, you want to put inside text. I have taken a flower picture.

Step 2: Select Horizontal type mask tool (T key) and modify format of the text as you like.

Step 3: Now write text on the taken new file, the picture will should be same.

Step 4: After written text select another tool in the toolbar, the selection picture will be appear.

Step 5: Now make copy and past on new layer that is you image inside text as I have done here.
