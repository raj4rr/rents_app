In this example, you are going to learn how to draw a heart graphic, I have used here very simple steps to learn easily, follow now to make a heart.

Step 1: Take a new file and select Custom shape tool (U key) and choose a heat card symbol as given here.

Step 2: Select Red color and draw a hear shape on the file

Step 3: Bevel and emboss effect, go to layer menu -> layer style -> Bevel and emboss and make settings.

Step 4: Give color overlay effect, go to Layer menu -> Layer style -> Color Overlay and select color as here.

Step 5: Give stroke effect, go to layer menu -> layer style -> Stroke and make settings.
