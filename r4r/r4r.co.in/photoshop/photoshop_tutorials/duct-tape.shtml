Make a Duct Tape
Previous Home Next

In this example you will learn how to draw duct tape graphic, I have tried here to make it so easy by one by one step, I think you can also make it by follow all the step.

Step 1: First take a new file with any size then select Rectangular Marquee tool (M key) and draw a rectangle shape.

Step 2: Set gradient effect, select Gradient tool (G key) and set color as here.

Step 3: Now drag by the mouse inside the selection to fill gradient effect as done up.

Step 4: Press Ctrl + J to make duplicate layer of the gradient effect then go to Filter menu -> Distort -> Ripple and make same settings.

Step 5: You will get this picture. press Ctrl + T, a selection will highlight. Now increase the selection area by the mouse as here.

Step 6: Come back to the gradient layer and make selection by the click of mouse on the gradient layer then press Ctrl + Shift + I to make inverse selection and press Del key.

Make sure you have this picture.

Step 7: Reduce opacity of the layer 100% to 30% you would have this picture.

Step 8: Make a new rectangle shape on the same picture and fill color #999fa2.

Step 9: Now change the blending mode 'normal' to 'linear light'.

Step 10: lets make wrinkle on the picture, make a selection by the Polygonal lasso tool (L key).

Step 11: give gradient overlay, go to layer menu -> layer style -> gradient overlay and make same setting.

Step 12: Use blur effect, go to Filter menu -> Blur -> Gaussian Blur and set radius as here.

You would get it.

Step 13: Use same step to make another wrinkle on the picture.
