Draw a Lock

In this example, you will learn how to draw lock. if you follow this tutorial, I am sure you will be able to draw a lock icon yourself so follow now.

Step 1: Take any new file with any background, select Rectangle tool (U key) and draw with any color on the file as here.

Step 2: Select Direct Selection tool (A key) and click on the figure to highlight the anchor point.

Step 3: Select Pen tool (P key) and make anchor point in between two anchor point and adjust as here.

Step 4: Give gradient effect, go to layer menu -> layer style -> gradient overlay and make same setting as here.

Step 5: Give stroke effect to the shape, go to layer menu -> layer style -> stroke and make same settings.

You would have this picture.

Step 6: Select Ellipse tool (U key) and draw then adjust with same gradient and stroke effect as done up.

Step 7: Select Pen tool (P key) and make point like lock handle as here.

Step 8: Give Bevel and emboss effect, go to layer menu -> layer style -> Bevel and emboss and make same settings as here.

Your lock is completed.
