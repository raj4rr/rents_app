Make a Magnify Text
Previous Home Next

In this example, you will learn a magnify text effect, you can magnify any type of text like news paper and magazine text. I hope you like this tutorials.

Step 1: Open a new file and set file size as you want, select Text tool (T key) and make text formatting as here then write text whatever you like.

Step 2: Select Elliptical Marquee tool (M key) and make a circle selection as looking here.

Step 3: Take a new layer and fill any color in the selection, I hare filled black color.

Step 4: Now go to Selection menu -> Modify -> and set contract '8px', the picture would be same here.

Step 5: Press Del key to delete the selected par of the circle shape.

Step 6: When you press del key this message will appear, click on ok button.

Step 7: Go to Filter menu -> Liquefy -> and select tool and press two time on the file.

Step 8: The liquefy text effect will be same, make handle of the magnify glass. Select Rounded rectangle tool (U key) and draw as given here.

The magnify text effect is completed.
