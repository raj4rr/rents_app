In this example, we are going to lean a simple method to draw a chain, this is easy tutorial because every step of the tutorial is clear to learn easily. You can also make it by follow all the steps.

Step 1: First take a new file with any size then choose Custom shape tool (U key), the property would highlight bottom of the menu bar. In the property bar select circle frame and draw on the file as I have done here.

Step 2: Now give gradient effect, go to layer menu -> layer style ->gradient overlay and make same settings of the colors and angle as here.

You get this picture.

Step 3: Give bevel and emboss effect, go to layer menu -> layer style -> bevel and emboss and make same setting.

Step 4: Now make duplicate layer of the chain and adjust layer as here. Select Eraser tool (E key) and click on the second layer then a message appear click on the ok.

Step 5: Go to first chain layer and hold Ctrl key and click on the layer, the first chain shape would be selected .

Step 6: Now go to second chain layer and select Eraser tool again then click inside the selection on the second chain layer as I have done here.

Step 7: Make setting of the second chain layer like chain that is your chain completed.
