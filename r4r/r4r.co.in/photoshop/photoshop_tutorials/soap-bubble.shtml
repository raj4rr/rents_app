You have been played with the soap bubble, now you can learn how to draw it in the Photoshop. Follow all the steps to draw same effect.

Step 1: Take any type of the background, I have taken here a gradient picture.

Step 2: Select Elliptical marquee tool (M key) and draw circle then fill color as here.

Step 3: Give stroke effect, go to layer menu -> layer style -> stroke and make same settings.

Step 4: Inner shadow effect, go to layer menu -> layer style -> Inner shadow and make same settings as here.

Step 5: Select Polygonal lasso tool (L key) and make selection on the bubble and fill white color.

Step 6: Go to Filter menu -> Blur -> Gaussian Blur and set radius '1.4' two times

The picture should be same.

Make duplicate bubble layer, adjust on different shape as I have done here.
