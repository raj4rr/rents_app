In this example you will lean a how to draw a white button by the Photoshop, this button can be used in the web page and for the print media.

Step 1: Take a new file as you need to draw button on, select Rectangle tool (U key) to draw a rectangle shape for the button with any color.

Step 2: Stroke effect, go to layer menu -> layer style -> stroke and make settings as here.

Step 3: Give gradient effect, go to layer menu -> layer style -> gradient overlay and make settings.

Step 4: Bevel and emboss effect, go to layer menu -> layer style -> Bevel and Emboss and make settings as given here.

Step 5: Select line tool (U key) and draw with white color same as here.

Step 6: Inner shadow effect, go to layer menu -> layer style -> Inner shadow and make settings.

The picture should be same.

Step 7: Now make duplicate layer and set as cross sign.
