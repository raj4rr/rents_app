Make a Circle Button
Previous Home Next

In this example, you will learn how to draw a circle button to use in the web. Need not to capture a button, I am sure you will be able to draw a web button yourself by this example.

Step 1: Take any size of the file and select Custom Shape tool (U key) and select circle frame then draw on the file with any color.

Step 2: Give gradient effect, go to layer menu -> Layer style -> gradient overlay and make same settings.

The picture should be same.

Step 3: Give bevel and Emboss and stroke effect, go to layer menu -> layer style -> Bevel and Emboss, Stroke and make same settings.

The picture should be same as here.

Step 4: Draw a Circle shape inside the shape with same color as I have done here.

Step 5: Give Bevel and Emboss effect, go to layer menu -> layer style -> Bevel and Emboss and make same settings.

You button is completed.
