Create a Plastic Text

In this tutorial, you will learn a simple way to make a plastic text effect with some easy steps. Use all the step those are given in this example to make same text effect.

Step 1: First take a new file and select text tool (T key) then make formatting of the text as given here.

Step 2: After selection text tool click on the file to write text on the file any text as you like.

Step 3: Use Bevel and Emboss effect, go to layer menu -> layer style -> Bevel and Emboss and make same settings.

Step 4: Use color overlay effect on the text, go to layer menu -> layer style -> color overlay and make same settings.

Step 5: Use stroke effect, go to layer menu -> layer style -> stroke and make same settings.
