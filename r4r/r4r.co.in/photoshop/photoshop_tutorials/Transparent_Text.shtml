Create Transparent Text
Previous Home Next

In this tutorial will teach you how to write a transparent text on the object, if you follow all the steps with carefully I am sure you can also write any type text on any object.

Step 1: I have selected here a grass field to write text, you can take any object as you like.

Step 2: Choose Text Tool (T key) and use same setting of the text properties as here.

Step 3: Now write text on the object as you selected.

Step 4: Make text selection, Press hold Ctrl key and mouse click on the text layer to make text selection.

Step 5: Now we have to increase width of the selection to fill color in the selection. Go to Select menu -> Modify -> Border and increase width "3" pixels as here.

Step 6: You will see like this picture, now hide text layer from the layer plates and take new layer.

Step 7: Set foreground color as you like to fill in the selection, after selection color fill by the paint bucket tool in the selection.
