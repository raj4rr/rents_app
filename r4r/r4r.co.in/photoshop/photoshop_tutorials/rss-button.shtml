In this example, I will teach you to draw your own rss button, it is so easy by my this example so follow to draw same as I have done here.

Step 1: Take a new file with any size as you like, select Elliptical marquee tool (M key) and draw a circle selection on the new layer and fill any color as you like, I have filled here a dark brown color.

Step 2: Give gradient effect, go to Layer menu -> layer style -> Gradient Overlay and make same settings as here.

You should have this picture.

Step 3: Now use same step to draw a white circle on the button as here.

Step 4: Select Line tool (U key) and draw a line on the button with white color and press Ctrl + T key then select 'warp' option.

Step 5: Make anchor point settings of the white line as here then set on the white circle.

Step 6: Make duplicate layer of the white line and set.
