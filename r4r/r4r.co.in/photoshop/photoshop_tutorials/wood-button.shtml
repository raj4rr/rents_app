In this example, I am going to draw a wood button to use in the web site, I have used here so simple steps to draw that, I am sure you can also make that by follow all the steps as given in this example.

Step 1: Take a new file with any size and background color, select Rectangle tool (U key) and draw a shape on the file as you have taken.

Step 2: Give Pattern effect, go to layer menu -> layer style -> Pattern Overlay and make settings as given here.

Step 3: Give Inner glow effect, go to layer menu -> layer style -> Inner glow and make settings.

Step 4: Give bevel and emboss effect, go to layer menu -> layer style -> Bevel and Emboss and make same settings as given here.

Step 5: Give stroke effect, go to layer menu -> layer style -> Stroke and make settings as given here.

This is your wood button.
