Make a No Smoking Message
Previous Home Next

This example will teach you how to draw a no smoking message for the banner and another print media. I have make with some steps to follow them to make completely as I have done in the example.

Step 1: Open a new file with any background color and select Ellipse tool (U key) and draw a circle with '#d2d2d0' color.

Step 2: Give gradient effect, go to layer menu -> layer style -> gradient overlay and select same color and settings.

Step 3: Give bevel and emboss effect, go to layer menu -> layer style -> Bevel and emboss and make settings.

Step 4: Give stroke effect, go to layer menu -> layer style -> stroke and make same settings.

Step 5: Give drop shadow effect, go to layer menu -> layer style -> Drop shadow and set color and values.

Step 6: Select Rounded rectangle tool (U key) and draw a line with white color.

Step 7: Make duplicate layer and set with the dark Red color.

Step 8: Select stop symbol from the custom shape tool (U key) and draw on the cigarette with Red color.

Step 9: Select Text tool (T key) and write on the button 'No Smoking' message with any color as you like.

Step 10: Select Create warped text tool from the text property and set value as given here.
