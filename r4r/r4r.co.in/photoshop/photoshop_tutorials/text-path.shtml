In this example, you are going to learn how to set your text on any type of path. I have used here some simple steps to make it, follow all the steps carefully, if you want same result as I have done here.

Step 1: Take a new file with any size and background color then choose Pen tool (P key) and and make same setting in the pen tool property as here.

Step 2: Now make point on the file by the pen tool as you selected.

Step 3: Take Text tool (T key) and modify the format of the text to write text on the path.

Step 4: Try to click text tool on the path until your text symbol as here.

Step 5: Write whatever text as you like on the path as I have written here.

Step 6: After written text on the path go to background layer, the path would be hide that is you path text completed.
