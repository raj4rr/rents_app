Make a Black Button
Previous Home Next

In this tutorial, I will teach you how to draw fantastic black button, some easy steps are being used in this example Follow all the steps to learn completely

Step 1: Take any size of the file, select Rectangle tool (U key) and draw with black color as here.

Step 2: Gradient effect, go to layer menu -> layer style -> Gradient and make same settings as I have done here.

Step 3: Give stroke effect, go to layer menu -> layer style -> Stroke and make same settings as here.

The picture should be same.

Step 4: Select elliptical marquee tool (M key) and draw a circle selection on the button.

Step 5: Select Rectangular Marquee tool (M key) and cut the selection with hold Ctrl key and mouse as here.

Step 6: Now Take a new layer and fill 'White' color and the selection then reduce the opacity of the layer '100%' to '16%'.

Step 7: Your button is completed now, you can write any text and use for the web.
