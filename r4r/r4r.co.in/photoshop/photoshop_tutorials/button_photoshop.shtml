If you are looking for a web button for use your website, this tutorial will surely help you. It has easy steps to make a attractive web button so lets try.

Step 1: First take a new file with any size and color as you like then choose Rectangle Tool (U key) and adjust same setting as given below

Step 2: Draw a rectangle shape on the file.

Step 3: Use gradient overlay effect, go to layer menu -> Layer style -> gradient overlay and adjust same setting as here.

Step 4: Use stroke effect, go to Layer menu -> Layer style -> Stroke and adjust same settings.

Step 5: You will have this picture.

Step 6: Draw a little another rectangle shape on with any color.

Step 7: Use gradient overlay as here.

Step 8: Your web button is completed, use it in the website.
