In this example, I am going to teach you how to make a arrow button, It is used in the web page to follow another page by the hyperlink. you can use anywhere as you like.

Step 1: Take a new file and select Elliptical Marquee tool (M key) and make a circle shape selection.

Step 2: Now fill any color, I have filled here black color.

Step 3: Use Gradient Overlay effect, go to layer menu -> layer style -> Gradient overlay and make same settings as here.

Step 4: Use Bevel and Emboss effect, go to layer menu -> layer style -> Bevel and Emboss and make same settings as here.

Step 5: Make again a circle shape selection inside the shape as done up.

Step 6: Now delete the selected part of the shape, press del key. Your picture will same as here.

Step 7: Select Custom shape tool (U key) and select arrow shape in the circle as here.

Step 8: Use bevel and emboss effect, go to layer menu -> layer style -> Bevel and emboss and make same settings.
