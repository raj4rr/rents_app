In this example I will teach you how to draw a real steel pipe, this tutorial has some effective and easy steps that makes it easy to lean completely.

Step 1: First take a new file with any size and any color as you like then select Rounded Rectangle Tool (U key) and draw a shape with any color as here.

Step 2: Use gradient effect, go layer menu -> layer style -> Gradient Overlay take same color and make same setting as here.

You would have same picture.

Step 3: Select Ellipse tool (U key) and draw a circle shape top on the pipe with any color.

Step 4: Use gradient Overlay effect, go to layer menu -> layer style -> gradient overlay and make same setting as here.

You will have this picture.

Use same all the step as done up to make another pipes as here.
