In this example I am going to teach you how to show drink in the glass, I have here a blank glass and going to add drink, Learn the technique follow this example.

Step 1: Take a blank glass picture to modify.

Step 2: Make selection, select Polygonal lasso tool ( L key ) and make selection as given here.

Step 3: Select foreground color "Red" and fill in the selection in the new layer then go to Filter menu -> Blur -> Gaussian Blur and set radius.

Step 4: Give gradient effect, go to layer menu -> layer style -> Gradient Overlay and make setting of the color as given here.

Step 5: Now draw a circle shape top of the drink with Ellipse tool (U key) as here.

Step 6: Give Inner glow, go to layer menu -> layer style -> Inner glow and make settings as here.
