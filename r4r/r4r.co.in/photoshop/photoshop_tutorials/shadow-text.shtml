I am sure you have seen shadow text in many web sites, now you have a chance to lean how can make that. follow and try to make that same as me here.

Step 1: Take a new file and select Text tool (T key) and modify the formatting as given here.

Step 2: Now write text, you can write any text as you like. I have written here my web name.

Step 3: Make duplicate layer of the text and press Ctrl + T and right click in the selection then choose 'Flip Vertical' as given here.

Step 4: Set duplicate text on the bottom of the main text as here.

Step 5: Now give gradient effect, go to layer menu -> layer style -> gradient overlay and make same settings.

Final shadow text
