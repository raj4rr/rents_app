In this example, you will learn a how to make web 2.0 type button for the web. Follow step by step this example to make same as I have done here.

Step 1: Take a new file with any size and select Rounded rectangle tool (U key) and take same color then draw on the file as here.

Step 2: Make duplicate layer and press Ctrl + T key and adjust by the mouse as here.

Step 3: Give gradient effect, go to layer menu -> layer style -> Gradient Overlay and make same settings as given here.

You picture should be same.

Step 4: Now take text tool to write text on the button as you like. I have written here 'submit'.
