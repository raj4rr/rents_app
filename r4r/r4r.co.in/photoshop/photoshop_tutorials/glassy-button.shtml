Make a Glassy Button

You have a chance to make glassy button to use in the website so don't miss this example. I am sure you can make same by use all the steps of this tutorials.

Step 1: Take any size of the file and select Ellipse tool (U key) and draw a circle with any color as you lime, I have draw with black color.

Step 2: Make duplicate layer of the black shape layer and press Ctrl + T key then modify the size as here.

Step 3: Give gradient effect, go to layer menu -> layer style -> gradient overlay and make same settings as here.

The picture should be same.

Step 4: Go to Filter menu -> Blur -> Gaussian Blur and set Radius '1.6px'.

Final glassy button
