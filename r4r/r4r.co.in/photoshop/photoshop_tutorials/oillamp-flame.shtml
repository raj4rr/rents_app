Make Oil Lamp Flame
Previous Home Next

In this example, I am going to teach you to draw flame on the oil lamp. You can draw flame on any place by using some steps those are given in the example.

Step 1: Take any picture to draw flame on that, I have selected a oil lamp picture to modify.

Step 2: Select Pen tool (P key) with '#f7f1d8' color and make anchor point like a flame as here.

Step 3: Give gradient effect, go to layer menu -> layer style -> gradient overlay and select same color and settings.

You should have this picture.

Step 4: Use motion blur, go to layer menu -> layer style -> motion blur and set angle and distance as given here.

Step 5: Now reduce layer opacity '100%' to '60%'
