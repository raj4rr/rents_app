Make a Neon Text

In this example, you will learn how to write a neon text effect by the Photoshop. I have used some tools here, follow this example to learn about that.

Step 1: Take any size of file as you need with black background.

Step 2: Select Text tool (T key) to write text on the file, after selection modify the formatting as you like and write as here.

Step 3: Give gradient effect, go to layer menu -> layer style -> gradient overlay and make color settings as here.

Step 4: Give outer glow effect, go to layer menu -> layer style -> Outer glow and make same settings as here.

You should have this picture.

Step 5: Go to Filter menu -> Blur -> Gaussian Blur and set radius '0.8'.
