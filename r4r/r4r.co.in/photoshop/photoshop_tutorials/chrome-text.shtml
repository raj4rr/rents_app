Make a Chrome Text
Previous Home Next

In this example, I will teach you to write a chrome text effect, it use to give a different look to your text. Learn about complete process to write chrome text follow this tutorials.

Step 1: Take a file to write text as you like and select Text Tool (T key) and modify the formatting to write same type text as here.

Step 2: Use drop shadow effect to make shadow under the text, go to Layer menu -> layer style -> Drop shadow and make same settings.

Step 3: Use bevel and emboss effect to give good look, go to layer menu -> layer style -> Bevel and emboss and make same setting as here.

Step 4: Use stroke to give border effect, go to layer menu -> layer style -> stroke and make same settings.

Step 5: Use color effect on, go to layer menu -> layer style -> color overlay and make same settings as here.

The chrome text is completed.
