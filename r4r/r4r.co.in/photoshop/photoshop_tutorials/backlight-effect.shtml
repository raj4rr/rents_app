Backlight Effect

In this example you will learn how to give a lighting effect backside of text, it is very easy to draw. I have done it only with four steps so follow now.

Step 1: Take a new file with black background and select Text tool (T key) and write text with blur color as here.

Step 2: Make duplicate layer of the text and press Ctrl + T to increase size of the text with change color 'Blur' to 'Orange'.

Step 3: Give Blur effect, go to Filter menu -> Blur -> Radial Blur and make settings.

Your backlight text effect is completed.
