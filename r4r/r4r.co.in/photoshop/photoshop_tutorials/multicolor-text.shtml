Make a Multicolor Text
Previous Home Next

In this example, you will learn how to add many color to the text. It is very simple, follow this tutorial to find our how is it possible.

Step 1: Take any size of the file as you need, select Text tool (T key) and write text on the file with any color.

Step 2: Add stroke, go to layer menu -> layer style -> Stroke and make same settings as here.

Step 3: Make selection, hold Ctrl and click on the text layer to make selection as here.

Step 4: Now take a new layer and fill blur color in the selection, you can fill any color as you like.

Step 5: Select Rectangular marquee tool (M key) and hold Alt key then cut the selection by the mouse as I have done here.

Step 6: Take a new layer and fill any color, I have filled here a orange color in the selection.

Step 7: Use same upper step to make multicolor text.
