Set up JME environment with NetBeans IDE
Previous Home Next

NetBean IDE also provide JME environment in it. Activate it form Plugin window or follow the steps describe below.

Step- 1:Go to Tool option and select Pluging form the tool list.

Step- 2:Choose Installed tab form pluging and activate Java ME plugin.

Step- 3:Once your ME plugin activate your IDE is capable of to Developed JME application within it.
