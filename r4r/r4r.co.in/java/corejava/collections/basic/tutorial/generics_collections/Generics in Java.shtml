Generics in Java

Generics is the part of Java programming language added as a part of J2SE 5.0( or JDK 1.5) in 2004. Generic allow the reference types( like classes, interface and array types) and methods to be parameterized with types information. Also, Generics allow to used the specified types of ADT( Abstract data Type, an ADT define both the types of objects and the operations that can be performed on these object.), so that same definition and behavior of an ADT can be used on different types of object.

Generics in java are the way to providing type information in ADTs, so that compiler can guarantee type- safety of operation at runtime because Generics are implemented at compile time. The primary benefit of Generics are increase language expressiveness with improved type safety, resulting in improve rousted and reliability of code. Generics avoid verbosity of using casts in many context, thus improving the code clarity. Generics is used extensively in implementing the java collections framework.

Syntax for Defining Simple Generics Interface

Example

package r4r.co.in;
import java.util.Iterator;

//Define a interface Generics and E is formal type parameter
interface Generics<E> {
//Define two method signature
void setData(E data);
E getData();
Iterator<E> iterator();
}

Parameterized type

A parameterized type( also called type instance) define as an invocation or instantiation of Generics, i.e. a specific usage of the generic type where the formal type parameters are replace by actual type parameter.

Some restrictions occur on use of type parameter in a Generic type

  1. A formal type parameter is a non-static type. It can't be used in a static context.
  2. A formal type parameter can't be used to create a new instance.
  3. A constructor declaration in a generics class can't specify the formal type parameters of the generics class.
