Subtyping in Generics
previous Home Next

Generally, Subtyping is a key feature of object-oriented languages such as Java. In java, one type is subtype of another if they are related by an implement or an extends clause. Also, Subtyping is transitive, that means if one type is a subtype of a second, and the second is a subtype of a third, then the first is a subtype of the third.

Here, some examples of Subtyping in java

Doubleis subtype of Number
Integeris subtype of Number
List <E> is subtype of Collection <E>
ArrayList <E>is subtype of List <E>
Collection <E>is subtype of Iterable <E>

Every reference type is a subtype of Object, and Object is a supertype of every reference type.
