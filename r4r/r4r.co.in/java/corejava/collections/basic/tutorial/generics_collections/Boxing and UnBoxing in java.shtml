Boxing and UnBoxing in Java Generics
previous Home Next

Conversion of a primitive type to the corresponding reference type is called boxing and conversion of the reference type to the corresponding primitive type is called unboxing. In Java, every type either reference type ( i.e. any class, instance, or array type )or or a primitive type ( i.e. subtypes of class Object, any variable of reference type may be set to the value null). As seen in the table, there are eight primitive types, and each one of these has a corresponding library class( which located in the package java.lang ) of reference type.

Difference between primitive and Reference type

Primitive typeReference
byteByte
shortShort
intInteger
longLong
floatFloat
doubleDouble
boolBoolean
charCharacter

In generics automatically inserts boxing and unboxing coercions where appropriate. Let consider a simple program

Example

/*
 * Save as a ArrayExample1.java
 * Program for Boxing in Generics.
 */
package r4r.co.in;
import java.util.ArrayList;
public class ArrayExample1 {
public static void main(String[] args) {
ArrayList<Integer> list = new ArrayList();
//Add five Interger into list
list.add(new Integer(1));   //int is converted into Interger called boxing
list.add(new Integer(2));
list.add(new Integer(3));
list.add(new Integer(4));
list.add(new Integer(5));
System.out.println("Element inside the List:" + list);
//Define a Empity array and fill it 
Object array[] = list.toArray();
int sum = 0;                     //initial sum=0
//Read every single value from array and add one by one.
for (int i = 0; i < array.length; i++) {
sum += ((Integer) array[i]).intValue();
}
System.out.println("Sum of all the Element:: " + sum);
}
}

output

Element inside the List:[1, 2, 3, 4, 5]
Sum of all the Element:: 15
