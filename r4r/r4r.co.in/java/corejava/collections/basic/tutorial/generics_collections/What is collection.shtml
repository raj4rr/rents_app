What is collection in java
previous Home Next

Collection is a interface, Part of java.util package and represents a group of objects, known as a elements of collection in order form or unordered form. All the class define into collection interface should be provide two standard types of constructor

  1. void (return no argument) constructor: Use for create an empty collection.
  2. Constructor( return a single argument) of collection: Use for creates a new collection with the same elements as its argument.

Different types of Collection in java

Collection in Java

  2. Iterators:Select each element in a collection.

Limitation of Collection

Collection have following limitation

  1. Collection object and variable can't check at the compile time.
  2. It is resizable, so utilize dynamically Allocated Memory.
  3. Command collection must be used for collect a data.
  4. Must cast to correct type( i.e. type casting).
  5. Major limitation of collection, It user use JVM 1.4.2 version, than this JVM software might be crash during data collection.
