Define a Growable ArrayList
previous Home Next

The ArrayList class extends AbstractList and implements the List interface. ArrayList supports dynamic arrays that can grow as needed, and also supported by the legacy class Vector.

Example

/*
 * Save as a ArrayExample.java
 * Program for Define a Growable ArrayList
 */
package r4r.co.in;
import java.util.ArrayList;
public class ArrayExample {
public static void main(String []args){
//Define a Growable ArrayList
ArrayList 
list=new ArrayList();
System.out.println("Size::" +list.size()+" and, Element inside the ArrayList:: " +list);
//Add some Element into ArrayList
list.add("A");
list.add("B");
list.add("C");
list.add("D");
list.add("E");
list.add("F");
list.add("G");
list.add(2, "s");   //Add the "s" into 2nd position 
System.out.println("Size::" +list.size()+" and, Element inside the ArrayList:: " +list);
//Remove some element from the ArrayList
list.remove("F");
list.remove(2);
System.out.println("Size::" +list.size()+" and, Element inside the ArrayList:: " +list);
//Replace element "C" with "Z"
list.remove("C");
list.add(2, "Z");
System.out.println("Size::" +list.size()+" and, Element inside the ArrayList:: " +list);
}
}

output

Size::0 and, Element inside the ArrayList:: []
Size::8 and, Element inside the ArrayList:: [A, B, s, C, D, E, F, G]
Size::6 and, Element inside the ArrayList:: [A, B, C, D, E, G]
Size::6 and, Element inside the ArrayList:: [A, B, Z, D, E, G]
