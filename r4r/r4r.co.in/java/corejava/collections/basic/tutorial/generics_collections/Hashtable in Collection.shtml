Hashtable in Collection
previous Home next

A Hashtable is a specialized Dictionary that relies on a hashing algorithm to convert keys into a mechanism to look up values in the dictionary. When the key-value pair using in a hashtable, the keys are converted into an integer called a hash code by using a hashing algorithm. Now, this hash code is then reduced based upon the internal storage structure used by the hash table to serve as an index into this structure (an array). In case of two equal elements present into Hashtable, the hash code must be the same.

Example

/*
 * Save as a HashTableExample.java
 * Program for HashTable
 */
package r4r.co.in;
import java.util.Enumeration;
import java.util.HashMap;
import java.util.Hashtable;
public class HashTableExample {
public static void main(String[] args) {
HashMap hmp = new HashMap();

// put the values to the Hashmap
hmp.put("12", "tweleve");
hmp.put("13", "thirteen");
hmp.put("14", "fourteen");
Hashtable tb = new Hashtable();
tb.put("1", "one");
tb.put("2", "two");
tb.put("3", "three");
// print the value of hashtable before copying the value Hashmap to Hashtable
System.out.println(" The  values of Hashtable are:");
Enumeration e = tb.elements();
while (e.hasMoreElements()) {
System.out.println(e.nextElement());
}
// now tocopy the elements of hashmap use putAll() method of hashtabble
tb.putAll(hmp);
System.out.println("Elements of Hashtable after copying");
e = tb.elements();
while (e.hasMoreElements()) {
System.out.println(e.nextElement());
}
}
}
