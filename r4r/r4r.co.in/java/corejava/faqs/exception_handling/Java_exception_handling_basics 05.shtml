Exception is Rethrowing in Java Programming
Previous Home Next

Rethrowing is a concept in which exception should be throw again and again. Lets consider an example.

// This program create for ReThrowing exception.
package r4r.co.in;
class MyException extends Exception {
MyException(int x) {
}
}
class MyException1 {
static void note(int t) throws MyException {
System.out.println("Called note(" + t + ")");
if (t > 10) {
throw new MyException(t);                       
//overhear exception should be Rethowing. by using keyword throw
}
System.out.println("Does Exception generate");
}
public static void main(String args[]) {
try {
note(5);
note(20);
} catch (MyException e) {
System.out.println("Exception Caught " + e);
}
}
}
Custom Exception Handlers in Java Programming

This is quite easy to generate the custom exception by define a subclass of Exception (which is a subclass of Throwable). That subclasses no need to actually implement anything the used as a exception .The exception class doesn't define any methods of its own and don't inherit any methods provided by Throwable class.

// This program creates a custom exception.
package r4r.co.in;
class MyException extends Exception
{
MyException(int x) {
//create a exception called MyException
}
}
class MyException1 {
public static void note(int t) throws MyException {
System.out.println("Called note(" + t + ")");
if(t > 10)
throw new MyException(t);
System.out.println("Does Exception generate");
}
public static void main(String args[]) {
try {
note(5);
note(12);
}
catch (MyException e)
{
System.out.println("Exception Caught " + e);
}
}
}
