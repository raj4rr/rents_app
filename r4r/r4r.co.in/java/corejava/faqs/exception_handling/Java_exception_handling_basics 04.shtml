Try, catch and finally in Java Programming

Keyword try-catch-finally is used for exception handling which generated by the Java run-time system (or java virtual machine, JVM ), or they can be manually generated by your code.

//following example of TryCatchFinally.
package r4r.co.in;
public class TryCatchFinally
{
public static void main(String args[]) throws Exception {
int i; 
//initialize local variable
int array[] = { 0,1,2,3,4,5,6,7,9 };
//initialize an array
{
try{      
// generate the exception in try block
for( i=0;i<10;i++)
{
int index = i+1;
i = array[ index ];
System.out.print(i);
}
}
}
catch(Exception e)    
// catch the exception
{
System.out.println( "\nArrayIndexOutOfBoundsException" +e.toString());
}
finally {System.out.println("Finally block");
// finally block utilize as code that must be executed
}
}
}
Generate and Handling Nested Exception in Java Programming

In some cases, more than one exception could be raised by a single piece of code. To handle this two or more catch clauses or nested try can be used, each catching contain a different type of exception. When an exception is thrown, each catch statement is inspected in order, and the first one whose type matches that of the exception is executed. After one catch statement executes, the others are bypassed, and execution continues after the try/catch block.

//An example of Handling NestedException.
package r4r.co.in;
class NestedException{
public static void main(String args[]) throws Exception {
try {//try block used 
int a=0;
int b = 40 / a;
try {// nested try block used
if (a == 1) {
a = a /(a - a);  // division by zero
}
if (a == 2) {
int c[] = {1};
c[40] = 100;  // generate an out-of-bounds exception
}
}
catch (ArrayIndexOutOfBoundsException e) {
System.out.println("Array index out-of-bounds: " + e);
}
}
catch (ArithmeticException e) {//generate an ArithmeticException
System.out.println("Divide by 0: " + e);
}
}
}
