Java exception classes are organised into a hierarchy and define in java.lang.Throwable package. The class hierarchy isn't starts with Exception but with a class called Throwable.

How Error and Exceptions is generated in Java Programming

Error and Exception is define in subclass of throwable class which belongs to java.lang.Throwable and java.lang.Exception package.

//following example consider for generating Error.
package r4r.co.in;
public class IndexoutofBoundException
{
public static void main(String args[]) throws Exception
{
int i;                                                      
//initialize local variable
int array[] = { 0,1,2,3,4,5,6,7,9 };       
//initialize an array
i=array[Integer.parseInt(args[0])];
System.out.println( "Demo program for ArrayIndexOutOfBoundsException" );
}
}
