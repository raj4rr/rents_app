Declaring Exceptions handling in Java Programming

In Java exception is an object that describes an exceptional condition (or in error form) that's occurred in a piece of code and handled using a try-catch-finally block within a program .When an exceptional condition arises, an object that representing the exception is created and thrown in the method that caused the error. Following syntax shows exception handling.

package r4r.co.in;
try {      
//Exception Code writing here
<code>
}
catch (<exception type> <parameter>)      
//catch block utilize as catch the exception
{ 
<statements>
}
} 
finally {       
<statements>     
// finally block utilize as code that must be executed
}
Catching Exceptions in Java Programming

Exceptions can be generated by the Java run-time system (or java virtual machine, JVM ), or they can be manually generated by your code. Java exception handlingis managed via five keywords: try, catch, throw, throws, and finally.

// Handle and generate an exception.
package r4r.co.in;
public class ArithmeticExceptionExp {
public static void main(String args[])throws Exception        
//throws keyword is used to throw the exception
{
int a= 0;           
//initialization local variable  in superclass
try       
//  Generate the exception.
{
int b = 10, c = 0;          
// initialize local variable in subclass

a = 10 /(b/c) ;
}
catch (ArithmeticException e)      
// catch the exception
{

System.out.println("Division by zero.");

a = 0;      }          
// set a to zero and continue

}
}
