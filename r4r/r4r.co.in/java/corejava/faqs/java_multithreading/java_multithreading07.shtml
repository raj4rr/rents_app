Thread Priority and Scheduling in Java Programming
Previous Home Next

When a Java thread is created, then thread scheduled provided the thread priority in integer value form. Thread priority can also modify by using the setPriority() method.

Thread priorities are integers ranging between MIN_PRIORITY and MAX_PRIORITY (constants defined in the Thread class). A higher priority thread is running first than lower priority thread.

Features of thread priority:

  1. JVM selects to run a Runnable thread with the highest priority.
  2. All Java threads have a priority in the range 1-10.Top priority is 10, lowest priority is 1.Normal priority ie. priority by default is 5.
  3. Thread.MIN_PRIORITY - minimum thread priority.
  4. Thread.MAX_PRIORITY - maximum thread priority.
  5. Thread.NORM_PRIORITY - default thread priority

Thread Scheduling: The thread of a parent process forks a child process. The child process inherits the scheduling policy and priority of the parent process.

Features of thread scheduling:
  1. The Java virtual machine(JVM) schedules using a preemptive , priority based scheduling algorithm.
  2. All Java threads have a priority and the thread with highest priority is scheduled to run first by the JVM.
  3. In case two threads have the same priority a FIFO(First in first out) ordering is followed.
  4. The currently running thread exits the Runnable state ie either blocks or terminates.
  5. A thread with a higher priority than the thread currently running enters the Runnable state. The lower priority thread is preempted and the higher priority thread is scheduled to run.
Daemon Threads in Java Programming

Daemon threads- The Thread which provide service to other threads running in the same process. In java any thread can be a daemon thread. To specify that a thread is a daemon thread, call the setDaemon(true) method on a thread object.

Example

//following example is consider for Daemon
package r4r.co.in;
class Daemon extends Thread {
Thread t = new Thread();
public Daemon()
{
setDaemon(true);
start();
}
public void run() {
try{
for (int i = 0; i < 5; i++)
System.out.println("t(" + i + ").Daemon() = " + t.isDaemon());
while (true)
yield();
}
catch(Exception e)
{
System.out.print(e);
}
}
}
class Daemonthread extends Thread {
public Daemonthread(int i) {
start();
System.out.println("Daemonthread " + i + " started");
}
public void run() {
while (true)
yield();
}
}
public class DaemonsExample {
public static void main(String[] args) throws Exception {
Thread d = new Daemon();
System.out.println("d.Daemon() = " + d.isDaemon());
Thread.sleep(1000);
}
}
