Multi-processing and Multi-tasking
Previous Home Next

Multiprocessing (also hyperthreading): It refers two or more processors each of which can simultaneously run a separate thread in one computer, like Windows NT is a symmetric multiprocessing (SMP) system, meaning that it assumes that all of the processors are equal and that they all have access to the same physical memory.

Multitasking : It has the ability of a computer to run more than one program (or task )at the same time. Multitasking also a single-tasking process, where one process must entirely and finish first before another can begin,

e.g. MS-DOS

: It is primarily a single-tasking environment, while Windows 3.1 and Windows NT are both multi-tasking environments. On a single-processor multitasking system, multiple processes don't actually run at the same time since there's only one processor. Multitasking also allows the computer to make good use of the time it would otherwise spend waiting for I/O devices and user input--that time can be used for some other task that doesn't need I/O at the moment. Multitasking is running multiple "heavyweight" processes (tasks) by a single OS.

Thread life cycle in Java Programming

Following state define as:

  1. New state : After the creations of Thread invocation the start() method id used for initialization the thread, before that thread should be not alive.
  2. Runnable (Ready-to-run) state: After start() method is perform then a thread first enter into runnable state after the invoking of start() method but a thread can return to this state after either running, waiting,sleeping or coming back from blocked state also.
  3. Running state: A thread is in running state that means the thread is currently executing.
  4. Block or waiting state: A thread can enter in this state due to waiting for the resources that are hold by another thread/program.
  5. Terminated or dead state: A thread can be considered dead when its Execution /run() method completes. If any thread comes on this state that means it cannot ever run again.
