Difference between jdk1.7, jdk1.5 and jdk1.6

Jdk 1.7 has some extra features

Some of are -

Features Added:

1)Java 1.7 runs faster than Java 1.5&java1.6

2)Support for dynamically-typed languages (InvokeDynamic): Extensions to the JVM,theJava language, and the Java SE API to support the emplementation of dynamically-typed languages atperformance levels near to that of the Java language itself.

3)Strict class-file checking: Class files of version 51 (SE 7) or later must be verified with the typechecking verifier; the JVM must not fail over to the old inferencing verifier.

4)Small language enhancements (Project Coin): A set of small language changes intended to simplify common, day-to-day programming tasks.

5)Strings in switch statements, try-with-resources statements, improved type inference for generic instance creation ("diamond"), simplified varargs method invocation, better integral literals, and improved exception handling (multi-catch).

6)Upgrade class-loader architecture: A method that frees the underlying resources, such as open files, held by a URLClassLoader

7)Concurrency and collections updates:

A lightweight fork/join framework, flexible and reusable synchronization barriers,transfer queues, concurrent linked double-ended queues, and thread-local pseudo-random number generators.
