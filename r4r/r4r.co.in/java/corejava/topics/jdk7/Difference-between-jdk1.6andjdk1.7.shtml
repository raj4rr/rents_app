jdk 1.6 Features added:

  1. Support for older win9x versions dropped.

  2. Scripting lang support: Generic API for integration with scripting languages, & built-in mozilla javascript rhino integration - Dramatic performance improvements for the core platform, and swing. - Improved web service support through JAX-WS JDBC 4.0 support - Java compiler API: an API allowing a java program to select and invoke a java compiler programmatically.

  3. Upgrade of JAXB to version 2.0: including integration of a stax parser. - Support for pluggable annotations - Many GUI improvements, such as integration of swingworker in the API.

  4. table sorting and filtering, and true swing double-buffering (eliminating the gray-area effect).

  5. Java 1.6 makes programming easier by implementing various tools such as SwingWorker and JTable to develop user interface.

jdk1.7 Features Added

  1. Support for dynamically-typed languages (InvokeDynamic).

    Java 1.7 runs faster than Java 1.6.

  2. Extensions to the JVM, the Java language, and the Java SE API to support the implementation of dynamically-typed languages at performance levels near to that of the Java language itself.

  3. Strict class-file checking: Class files of version 51 (SE 7) or later must be verified with the typechecking verifier.

  4. The VM must not fail over to the old inferencing verifier.

  5. Small language enhancements (Project Coin): A set of small language changes intended to simplify common, day-to-day programming tasks.

  6. Strings in switch statements.

  7. try-with-resources statements.

  8. improved type inference for generic instance creation ("diamond"), simplified varargs method .

  9. invocation, better integral literals, and improved exception handling (multi-catch).

  10. Upgrade class-loader architecture: A method that frees the underlying resources, such as open files, held by a URLClassLoader

  11. Concurrency and collections updates.

  12. A lightweight fork/join framework, flexible and reusable synchronization barriers, transfer queues, concurrent linked double-ended queues, and thread-local pseudo-random number generators.
