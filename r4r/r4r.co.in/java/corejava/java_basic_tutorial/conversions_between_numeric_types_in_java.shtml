Conversions between Numeric Types in Java
Previous Home Next

In java there are two type of conversions between numeric types:

  1. Widening primitive conversion and
  2. Narrowing Primitive conversion

These conversions are applying for integers

  1. Widening primitive Conversion:

    2. Widening conversion are very simple. There is no cast required and will never result in a runtime exception. precision may be lost when converting from integer to floating point types.

    bytetoshort, int, long, float, or double
    shorttoint, long, float, or double
    chartoint, long, float, or double
    inttolong, float, or double
    longtofloat or double
    floattodouble

    Example :

    int i = 65;
long l = i;

class WideningConversion 
{
	public static void main(String[] args)
	{
		int i = 123456789;
		float f = i;
		System.out.print(f);
	}
}

    Output :

    1.23456792E8

  2. Narrowing Primitive Conversion:

    3. Cast required between types. Overflow and underflow may happen but a runtime exception will never happen. In case of narrowing conversion from long (64 bit) to int (32) bit we have 32 fewer bits in the destination number. The following integer type conversions are the narrowing ones.

    shorttobyte or char
    chartobyte or short
    inttobyte, short, or char
    longtobyte, short, char, or int
    floattobyte, short, char, int, or long
    doubletobyte, short, char, int, long, or float

    Example :

    long l = 656666L;
int i = (int) l;
