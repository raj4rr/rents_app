Syntax

Access_Specifier class class-Name
{
	public static void main(String args[]) or (String []args)
	{
	}
}
  1. The Acess_ Specifier may be public, private, protected or default. It depends type of class.
  2. Class is a keyword which is used to create a class.
  3. Class _Name is userdefined type which is not include in class name keywords or reserve words.
First Java Program
class Hello
{
	public static void main(String args[])
	{
		System.out.print("Hello Delhi");
	}
}

Hello Delhi
