  1. In java every statement terminate with semicolon(;).
  2. Statements generally contain expressions (expressions have a value).
  3. One of the simplest is the Assignment Statement.

    4. Syntax :

    <variable> = <expression>;

    Example :

    int height;
height = 34;
  4. Declaration Statement.
    5. int number;
  5. Expression Statement.
    6. number = 4;
  6. Control flow Statement.
    7. if (number < 10 ) 
{
	//expression statement 
	System.out.println(number + " is less than ten");
}
  7. Increment Statement.
    8. a++;
  8. Method Invocation Statement.
    9. System.out.println("Hello World!");
  9. Object Creation Statement.
    10. Bicycle myBike = new Bicycle();
  10. Control Statements.

    11. Java also has control statements that allow repetitive execution of statements and conditional execution of statements. Java has the following types of control statements.

    1. Conditional Execution And Selection.

      2. If Statements - conditional execution of a single statement.

      If-Else Statements - conditional selection among two statements.

      Switch Statements - conditional selection among several statements.

      Extended If-Else Statements - conditional selection among several statements.

    2. Repetition.

      3. While Loops - pretest loops.

      For Loops - pretest loops.

      Do-While Loops - posttest loops.

    3. Special Control Statements.

      4. Return Statements - return values from and terminate methods.

      Continue Statements - skip the remaining statements in an iteration of a loop.

      Break Statements - exit a loop or switch statement.
