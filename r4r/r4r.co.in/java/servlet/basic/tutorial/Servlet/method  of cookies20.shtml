Methods of Cookies:-

                  Commonly used methods of cookies are as follows:-

getName():- is used to obtain the name of cookie

Syntax:

          public String getName();

getValue():- is used obtaion the value of cookie.

Syntax:-

           public String getValue();

setMaxAge():- is used to specify the time for which cookies remains valid.It is used to make a cookie persistent.



Syntax:-

          public void setMaxAge();

addCookie():- Method of HttpServletResponse interface is used to send a cookie as part of response.

Syntax:-

          public void addCookie(Cookie ck);

getCookies ():- Method of HttpServletRequest interface is used to receive cookies received as part of request.

Syntax:-

          public Cookie[] getCookies();

Advantage of Cookies:-

                The main advantage of cookies is simplicity.

Disadvantage of Cookies:-

1) This method of state management is browser dependent.

2) Only textual information can be persisted using this approach.

3)Persistent cookies doesn't differenciate between each other.
