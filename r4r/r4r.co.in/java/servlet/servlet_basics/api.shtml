Servlet API

The javax.servlet and javax.servlet.http packages represent interfaces and classes.

It is contained many interfaces and classes which is used by the servlet or web container,and not specific to any protocol.

It is also contains interfaces and classes taking a responsible for http requests only.

  1. Servlet

  3. ServletResponse
  4. RequestDispatcher
  5. ServletConfig
  6. ServletContext

  10. FilterChain
