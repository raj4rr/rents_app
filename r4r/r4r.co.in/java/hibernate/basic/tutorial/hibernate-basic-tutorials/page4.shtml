Disadvantages Of Hibernate
Previous Home Next

The following disadvantages of hibernate are

  • Everything is an object. If you need only a portion of data (say, for a search), you would still have to retrieve the object.
  • Sometimes debugging and performance tuning becomes difficult.
  • For complex data, mapping from object to tables and vice-versa reduces performances.
  • It is something difficult for the beginners.
