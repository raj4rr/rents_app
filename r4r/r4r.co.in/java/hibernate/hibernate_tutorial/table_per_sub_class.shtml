The three strategies

Hibernate supports the three basic inheritance mapping strategies:

  1. table per class hierarchy
  2. table per subclass
  3. table per concrete class

Hibernate and JPA support three main inheritance mapping strategies. Each has its own tradeoffs regarding database normalization, query performance, and integrity.

  1. SINGLE_TABLE (Table per class hierarchy)
  2. JOINED (Table per subclass)
  3. TABLE_PER_CLASS (Table per concrete class)
1. SINGLE_TABLE Strategy

In this strategy, the entire class hierarchy is mapped to a single database table. A "discriminator column" is used to distinguish which specific subclass a row belongs to.

  • Pros: Very fast queries (no joins required).
  • Cons: Subclass-specific columns cannot have NOT NULL constraints.

@Entity
@Inheritance(strategy = InheritanceType.SINGLE_TABLE)
@DiscriminatorColumn(name = "PAYMENT_TYPE")
public abstract class Payment { ... }

@Entity
@DiscriminatorValue("CREDIT")
public class CreditCardPayment extends Payment { ... }
2. JOINED Strategy

In this strategy, each class in the hierarchy gets its own table. The subclass tables only hold the columns specific to that subclass, plus a primary key that also acts as a foreign key to the superclass table.

  • Pros: Clean relational model (3NF). Subclass columns can be NOT NULL.
  • Cons: Queries require JOIN operations, which can be slower for deep hierarchies.

@Entity
@Inheritance(strategy = InheritanceType.JOINED)
public abstract class Payment { ... }

@Entity
@PrimaryKeyJoinColumn(name="PAYMENT_ID")
public class CreditCardPayment extends Payment { ... }
3. TABLE_PER_CLASS Strategy

In this strategy, each concrete subclass gets its own table. Each table contains columns for all properties of the subclass, including inherited properties.

  • Pros: No joins required for subclass-specific queries.
  • Cons: Polymorphic queries (e.g., querying for the base class) require expensive SQL UNION operations across multiple tables.

@Entity
@Inheritance(strategy = InheritanceType.TABLE_PER_CLASS)
public abstract class Payment { ... }

@Entity
public class CreditCardPayment extends Payment { ... }
