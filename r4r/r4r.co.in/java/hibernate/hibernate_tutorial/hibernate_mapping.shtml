In modern Hibernate, object-relational mapping (ORM) is primarily achieved using standard JPA (Java Persistence API) annotations. These annotations allow you to define exactly how your Java classes (Entities) map to your database tables, without the need for complex XML files.

1. The @Entity and @Table Annotations

The @Entity annotation marks a Java class as a persistent entity. Hibernate will map this class to a database table. By default, the table name matches the class name, but you can explicitly specify the table name using the @Table annotation. 


import javax.persistence.Entity;
import javax.persistence.Table;

@Entity
@Table(name = "employee_records")
public class Employee {
    // ... fields and methods ...
}

2. Primary Keys: @Id and @GeneratedValue

Every entity must have a primary key, mapped using the @Id annotation. You can let the database automatically generate these keys using the @GeneratedValue annotation. 


import javax.persistence.Id;
import javax.persistence.GeneratedValue;
import javax.persistence.GenerationType;

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

GenerationType.IDENTITY is commonly used with MySQL to rely on auto-increment columns.

3. Mapping Columns: @Column

By default, every field in your entity is mapped to a column with the same name. If your database columns use different naming conventions (like snake_case), you use @Column to map them. You can also specify column lengths and constraints. 


import javax.persistence.Column;

    @Column(name = "first_name", nullable = false, length = 50)
    private String firstName;
Association Mapping (Relationships)

Hibernate excels at managing relationships between different entities. These map to foreign keys in your database.

Types of Association Mapping:

  1. @OneToOne: A person has exactly one passport.
  2. @OneToMany: A department has many employees.
  3. @ManyToOne: Many employees belong to one department.
  4. @ManyToMany: Many students enroll in many courses.

import javax.persistence.ManyToOne;
import javax.persistence.JoinColumn;

    // Example of a ManyToOne mapping inside an Employee class
    @ManyToOne
    @JoinColumn(name = "department_id")
    private Department department;
Basic Data Types Mapping

Hibernate automatically translates standard Java types into corresponding SQL types. For example:

Java TypeANSI SQL Type
java.lang.StringVARCHAR
java.lang.Integer / intINTEGER
java.lang.Long / longBIGINT
java.util.DateTIMESTAMP / DATE
java.lang.Boolean / booleanBIT / BOOLEAN
