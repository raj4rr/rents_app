When mapping an entity to a database table, you often need to specify additional configuration, such as the exact table name, database schema, or catalog. In legacy Hibernate, this was done using the <hibernate-mapping> XML tag. In modern Hibernate, we configure this directly on our Java classes using JPA annotations.

Modern JPA Approach: @Table and @Entity

The @Entity annotation marks a class as a persistent entity. The @Table annotation allows you to specify the details of the table that will be used to persist the entity in the database.

Specifying Schema and Catalog

If your database uses schemas or catalogs to organize tables, you can specify them using the schema and catalog attributes of the @Table annotation. 


import javax.persistence.Entity;
import javax.persistence.Table;
import javax.persistence.Id;
import javax.persistence.GeneratedValue;

@Entity
@Table(
    name = "CUSTOMER_DATA", 
    schema = "SALES_SCHEMA", 
    catalog = "CRM_CATALOG"
)
public class Customer {

    @Id
    @GeneratedValue
    private Long id;

    private String name;
    
    // Getters and Setters...
}

By default, if you only use @Entity without @Table, Hibernate will assume the table name is the same as the class name. If multiple classes share the same name in different packages, you should explicitly define the table name to avoid naming collisions in the database.
