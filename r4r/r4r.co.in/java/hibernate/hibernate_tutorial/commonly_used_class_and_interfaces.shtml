Commonly Used Class and Interface

Hibernate provides a core set of interfaces and classes that you will use in almost every application to interact with the database. Below are the most commonly used ones:

1. Configuration

The Configuration class is typically the first object created in a Hibernate application. It is responsible for reading the Hibernate configuration file (e.g., hibernate.cfg.xml) and mapping files, and is used to bootstrap and build the SessionFactory.

2. SessionFactory

The SessionFactory interface is a thread-safe, immutable factory for creating Session instances. Because it is heavy-weight and expensive to create, typically only a single SessionFactory is instantiated per database during application startup and shared across the entire application.

3. Session

The Session interface is the primary interface used to perform CRUD (Create, Read, Update, Delete) operations on database entities. It wraps a JDBC connection and serves as a factory for Transaction and Query objects. A Session is a light-weight, non-thread-safe object that represents a single unit of work and should be opened and closed quickly.

4. Transaction

The Transaction interface represents a single unit of work with the database. It is used to demarcate transaction boundaries, allowing you to commit or rollback changes. In modern applications, all database interactions should occur within an active transaction.

5. Query and TypedQuery

The Query interface (and its modern JPA equivalent, TypedQuery) allows you to execute Hibernate Query Language (HQL) or native SQL queries. It provides methods to bind query parameters, limit the number of returned results, and retrieve the final query result list.

6. CriteriaBuilder and CriteriaQuery

The CriteriaBuilder and CriteriaQuery interfaces are part of the JPA Criteria API. They are used to construct type-safe, object-oriented queries programmatically. This approach is highly recommended when building complex, dynamic queries where appending strings together would be error-prone.
