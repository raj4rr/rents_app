We are going to give a simple example of the RMI where we will come to know how RMI works and what are the steps of executions. Here listed four java files and steps for executing this application.

Step 1: Create RemoteInterface.java Interface

package r4r;
import java.rmi.*;
public interface RemoteInterfaces extends Remote
{
  public int add(int a,int b)throws Exception;
}

Step 2: Create ServerImplements.java Class

package r4r;
import java.rmi.*;
import java.rmi.server.*;
import java.lang.String;
interface RemoteInterface extends Remote
{
  public int add(int a,int b)throws Exception;
}
public class ServerImplements extends
UnicastRemoteObject implements RemoteInterfaces
{
public void ServerImplements()throws Exception
{
super();
}
public int add(int a,int b)
{
return (a+b);
}
}

Step 3: Create the Server.java class

package r4r;
import java.rmi.*;
import java.net.*;
public class Server {
public static void main(String args[])
{
try
{
ServerImplements si=new ServerImplements();
Naming.rebind("SERVICE",si);
System.out.println("Server Start");
}
catch(Exception ex)
{
System.out.println(ex.getMessage());
}
}
}

Step 4: Create the client.java class

package r4r;
import java.rmi.*;

catch(Exception ex)
