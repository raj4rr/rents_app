Exploring Java.lang

Q.1 java.lang package is automatically imported into all programs.

(a). True

(b). False

Answer: (a). True

Q.2 What are the interfaces defined by java.lang?

Answer: Cloneable, Comparable and Runnable.

Q.3 What are the constants defined by both Float and Double classes?

Answer:

  • MAX_VALUE,
  • MIN_VALUE,
  • NaN ,
  • POSITIVE_INFINITY,
  • NEGATIVE_INFINITY and
  • TYPE.
Q.4 What are the constants defined by Byte, Short, Integer and Long?

Answer:

  • MAX_VALUE,
  • MIN_VALUE,and
  • TYPE.
Q.5 What are the constants defined by both Float and Double classes?

Answer:

  • MAX_RADIX,
  • MIN_RADIX,
  • MAX_VALUE,
  • MIN_VALUE and
  • TYPE.
Q.6 What is the purpose of the Runtime class?

Answer: The purpose of the Runtime class is to provide access to the Java runtime system.

Q.7 What is the purpose of the System class?

Answer: The purpose of the System class is to provide access to system resources.

Q.8 Which class is extended by all other classes?

Answer: Object class is extended by all other classes.

Q.9 Which class can be used to obtain design information about an object?

Answer: The Class class can be used to obtain information about an objects design.

Q.10 Which method is used to calculate the absolute value of a number?

Answer: abs( ) method.

Q.11 What are E and PI?

Answer: E is the base of the natural logarithm and PI is the mathematical value pi.

Q.12 Which of the following classes is used to perform basic console I/O?

(a). System

(b). SecurityManager

(c). Math

(d). Runtime

Answer: (a). System

Q.13 Which of the following are true?

(a). The Class class is the superclass of the Object class.

(b). The Object class is final.

(c). The Class class can be used to load other classes.

(d). The ClassLoader class can be used to load other classes.

Answer:

(c). The Class class can be used to load other classes.

(d). The ClassLoader class can be used to load other classes.

Q.14 Which of the following methods are methods of the Math class?

(a). absolute( )

(b). log( )

(c). cosine( )

(d). sine( )

Answer: (b). log( )

Q.15 Which of the following are true about the Error and Exception classes?

(a). Both classes extend Throwable.

(b). The Error class is final and the Exception class is not.

(c). The Exception class is final and the Error is not.

(d). Both classes implement Throwable.

Answer: (a). Both classes extend Throwable.

Q.16 Which of the following are true?

(a). The Void class extends the Class class.

(b). The Float class extends the Double class.

(c). The System class extends the Runtime class.

(d). The Integer class extends the Number class.

Answer: (d). The Integer class extends the Number class.

Q.17 Which of the following will output -4.0

(a). System.out.println(Math.floor(-4.7));

(b). System.out.println(Math.round(-4.7));

(c). System.out.println(Math.ceil(-4.7));

(d). System.out.println(Math.Min(-4.7));

Answer: (c). System.out.println(Math.ceil(-4.7));
