R4R Java Andriod Tutorials Use Android

Why to use Android:-

 1. Android have simple and powerful SDK
2. Developer can easy to Import third party Java library.
3. Android is open source technology ,So Licensing, Distribution or Development fee is not required.
4. We can run Android technology in any platforms like Linux, Mac Os, Windows etc.
5. The Android  is used on smartphones, netbooks, tablet computers, Google TV, and other devices.

6. The main hardware platform for Android is the ARM architecture. There is support for x86 from the Android-x86 project, and Google TV uses a special x86 version of Android.
