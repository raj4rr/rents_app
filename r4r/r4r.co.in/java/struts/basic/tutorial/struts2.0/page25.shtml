Introduction:

The ModelDriven interceptor is used to push a model object into the ValueStack show that its property can be directly access.

Class/Library File Descriptions:

ModelDriven interceptor work is association in with ModelDriven Interface which is provided by framework i.e if an action wants to push a model object into the valuestack with the help of ModelDriven interceptor then it need to implements ModelDriven interface. This interface provide one method getModel().

public Object getModel();

RegisterAction.java
package mypack;
import com.opensymphony.xwork2.ModelDriven;
public class RegisterAction implements
	ModelDriven<Address> {
User user;
public Address getModel(){
user=new User();
return user.getAddress();
}
public String execute()
{
return "success";
}
public User getUser() {
return user;
}
public void setUser(User user) {
this.user = user;
}
}
