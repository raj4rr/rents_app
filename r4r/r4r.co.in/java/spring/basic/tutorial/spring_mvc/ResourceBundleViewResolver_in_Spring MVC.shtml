This view resolver provide the facility to read all information which are typically defined in a properties file located in the class path.The default bundle basename is "views".

Syntax:

public class ResourceBundleViewResolver
extends AbstractCachingViewResolver
implements Ordered, DisposableBean

This view resolver provide the following method:

setOrder:

public void setOrder(int order)

getOrder:

public int getOrder()

setBasename:

public void setBasename(String basename)

setBasenames:

public void setBasenames(String[] basenames)

setBundleClassLoader:

public void setBundleClassLoader
(ClassLoader classLoader)

getBundleClassLoader:

protected ClassLoader getBundleClassLoader()

setDefaultParentView:

public void setDefaultParentView
(String defaultParentView)

setLocalesToInitialize:

public void setLocalesToInitialize
(Locale[] localesToInitialize)

initApplicationContext:

protected void initApplicationContext()
throws BeansException)

loadView:

protected View loadView(String viewName,
Locale locale)throws Exception

initFactory:

protected BeanFactory initFactory(Locale locale)
throws BeansException

getBundle:

protected ResourceBundle getBundle(String basename,
Locale locale)throws MissingResourceException

destroy:

public void destroy()throws BeansException
