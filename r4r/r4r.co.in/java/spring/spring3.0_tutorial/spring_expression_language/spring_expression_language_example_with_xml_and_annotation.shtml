Expression support for defining bean definitions

SpEL expressions can be used with XML or annotation-based configuration metadata for defining BeanDefinitions. In both cases the syntax to define the expression is of the form:

#{<expression string>}

The SpEL are enclosed with #{ SpEL expression }, see below example in XML bean definition file.

Example

<beans xmlns="http://www.springframework.org/schema/beans"
xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
xsi:schemaLocation="http://www.springframework.org/schema/beans
http://www.springframework.org/schema/beans/spring-beans-3.0.xsd">

<bean id="empBean" class="com.r4r.Employee">
<property name="name" value="John Smith" />
<property name="age" value="30" />
</bean>

<bean id="studBean" class="com.r4r.Student">
<property name="name" value="#{empBean}" />
<property name="studName" value="#{empBean.name}" />
</bean>
 
</beans>

#{empBean} add empBean into studBean beans name property.

#{empBean.name} add empBeans name property into studBean beans studName property.

Spring EL in Annotation(Annotation-based configuration)

The @Value annotation can be placed on fields, methods and method/constructor parameters to specify a default value.

  1. This is the first class.
    2. package com.r4r
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

@Component("studBean")
public class Student {

@Value("#{empBean}")
private Name name;

@Value("#{empBean.name}")
private String studName;

//...
}
  2. This is the second class.
    3. package com.r4r
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

@Component("empBean")
public class Employee {

@Value("John Smith") //inject String directly
private String name;

@Value("30") //inject interger directly
private int age;

public String getName() {
return name;
}
//...
}
