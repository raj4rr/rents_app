Variable in Spring Expression Language(SpEL)
Previous Home Next

Variables can be referenced in the expression using the syntax #variableName. Variables are set using the method setVariable on the StandardEvaluationContext.

Employee emp = new Employee("John Smith", "Model");
StandardEvaluationContext context = new StandardEvaluationContext(emp);
context.setVariable("newName", "John Smith");
parser.parseExpression("Name = #newName").getValue(context);
System.out.println(emp.getName()) // John Smith

Example

Create the Java class like (Square.java).

package com.r4r;
public class Square {
	private int n;  
	 	public int getN() {
		return n;
	}
	public void setN(int n) {
		this.n = n;
	}
	public int square(){  
	    return n*n;  
	}  
	}

Create the another Java class like (Main.java).

package com.r4r;
import org.springframework.expression.ExpressionParser;  
import org.springframework.expression.spel.standard.SpelExpressionParser;  
import org.springframework.expression.spel.support.StandardEvaluationContext;  

public class Main {  
public static void main(String[] args) {  
Square sq=new Square();  
StandardEvaluationContext context=new StandardEvaluationContext(sq);  

ExpressionParser parser = new SpelExpressionParser();  
parser.parseExpression("n").setValue(context,"10");  
System.out.println(sq.square());  
}  
}
