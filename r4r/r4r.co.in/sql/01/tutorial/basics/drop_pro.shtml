OUTPUT Parameter

  • To return a single value of integer type
  • To return more than one value from the procedure
  • This is supplied as an OUTPUT parameter to the procedure

Syntax

CREATE PROCEDURE  proc_name
[
{ @parameter data_type } [OUTPUT]
]
AS
sql_statement[...n]

The @parameter data_type [OUTPUT] allows the stored procedure to pass a data value back to the calling procedure. If the OUTPUT keyword is not used, then the parameter is treated as an input parameter, as seen before. A procedure can take both input and output parameter.
 

DROP STATEMENT

If you not require a stored procedure, you can drop it from database by using DROP PROCEDURE statement

Syntax

DROP PROCEDURE   proc_name

You can not retrieve procedure once it is dropped
