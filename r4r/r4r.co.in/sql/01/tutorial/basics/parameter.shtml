PASSING PARAMETER TO THE PROCEDURE

Parameter: A parameter is a placeholder in a query or a stored procedure that accepts a user-defined value whenever the query or stored procedure is executed.

Passing parameter to the Procedure

The parameters declared in the parameter declaration section serve as a means for data to be exchanged between the stored procedure and the object that has invoked it, also known as caller or invoker. 

The stored procedure have two types of parameter:

  • Input Parameter: It allow the invoker to pass the data value to the procedure
  • Output Parameter: It allows the stored procedure to the pass data value back to the invoker

For Example

CREATE PROC  addressList @city char(15)
AS
BEGIN
SELECT  emp_name,emp_sal
FROM  employee
WHERE  emp_add=@city
END

Out Put

The command (s) completed successfully.

sp_helptext  addressList

Out Put

Execute the procedure with an existing value

addressList  lucknow

Out Put


Execute the procedure with a non-existing value

addressList  jaunpur

Out Put

No value display
