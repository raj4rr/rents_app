The ALTER  PROCEDURE Statement

  • ALTER PROCEDURE Statement used to modify an existing procedure

  • Drooping the procedure might also affect some dependent procedure or other database objects, to avoid this problems should be used ALTER PROCEDURE statement

  • In case you do not pass any parameter to a procedure, it would generate an error message. The value passed a default value or NULL

For Example

ALTER PROCEDURE  addressList @name char(15)
AS
BEGIN
IF  @name is null
BEGIN
RETURN
END
SELECT  emp_sal, emp_add
FROM  employee
WHERE  emp_name=@name
END

The command (s) completed successfully.

sp_helptext  addressList

Out Put
