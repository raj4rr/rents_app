Displaying Specific Attributes From a Table

Guideline

  • Identify the output requirements of a query
  • While queering a database, often you need to view only specific columns, then you decide on the column heading required in the report

Draft the Query

1. The SELECT Statement

SQL server provide the SELECT statement to retrieve data  from database. The keywords SELECT, FROM and WHERE makeup the basic SELECT statement . SELECT statement promote the server to querying single table or multiple tables in Database and prepare a result and return to the client application.

Selecting Columns

The column name from a table specified in the SELECT statement separated by a comma (,) and there is no need to insert a comma after the last column name.

SELECT column_name1,column_name2..
FROM table_name

The above query retrieve the column data  which you pass in the query from table which you pass after From keyword.

Selecting All Columns

The SELECT statement used with an asterisk (*) symbol to display all column of the table

SELECT *
FROM table_name
