The following requirements apply to install MySQL 5.6.20 version:

  1. Framework: MySQL Server Setup installs the following software components required by the product:
    • NET Framework 4.0
  2. Internet Software: Microsoft Internet Explorer 7 SP1 or a later version is required for all installations.

Minimum Hardware requirements

  1. Processor:
    • Processor type: Pentium IV-compatible processor or faster.
    • Processor speed: Minimum: 2.0 GHz, Recommended: 2.0 GHz or faster
  2. Operating System:
    • Windows XP(64)
    • Windows Vista 64-bit x64 Ultimate
    • Windows 7 64-bit
    • Windows 8 64-bit
  3. Memory (i.e RAM):
    • Minimum: 2 GB
    • Recommended: 2.048 GB or more
  4. Features and Disk Space Requirement:
  • Database Engine and data files, Replication, and Full-Text Search : 280 MB
