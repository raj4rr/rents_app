FLOATS AND DOUBLES-

A float occupies four bytes in memory and can range from -3.4e38 to +3.4e38. If this is insufficient then C offers a double data type that occupies 8 bytes in memory and has a range from -1.7e308 to +1.7e308. A variable of type double can be declared as,

              double a, population ;

If the situation demands usage of real numbers that lie even beyond the range offered by double data type, then there exists along double that can range from -1.7e4932 to +1.7e4932. A long double occupies 10 bytes in memory.
