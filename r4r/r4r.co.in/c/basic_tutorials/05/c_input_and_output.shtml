printf() Function

This is one of the most frequently used functions in C for output.

#include <stdio.h>
main()
{
	int num = 5;
	char str[] = "mini";
	char ch = 's';
	float pi = 3.14;
	printf("%d %s %f %c\n", num, str, pi, ch);
}
