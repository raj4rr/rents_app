Web Technology
  • Web Technology

    Web technology is the development of the mechanism that allows two of more computer devices to communicate over a network.
  • Javascript

    Javascript is a scripting programming language that is used to make web pages interactive.
  • CSS

    Cascading Style Sheet (CSS) is made up of style rules that tell a browser how to present a document.
  • XML

    Extensible Markup Language (XML) is a specification developed by the World Wide Web Consortium (W3C).
  • HTML

    HTML stands for HyperText Markup Language for describing web documents.
  • PhotoShop

    Adobe Photoshop is a graphics editing program used for making attaractive images.
  • VBScript

    VBScript is a light version of Microsoft's scripting programming language for Windows operating systems .
  • Software Testing

  • RSS

    RSS stands for Really Simple Syndication is a lightweight XML format used to designed for sharing headlines and other Web content.
  • XForms

    XForms is an XML format used for collecting inputs from web forms W3C to develop the next generation of forms technology.
  • XHTML

    XHTML stands for EXtensible HyperText Markup Language that is supported by all major browsers.
  • XPath

    XML Path Language, is a query language for selecting nodes from an XML document defined by the World Wide Web Consortium.
  • XQuery

    XQuery is a query and functional programming language designed to query and transform collections of structured and unstructured data.
  • XSLT

    XSLT(Extensible Stylesheet Language Transformations) is a language for transforming XML into other XML documents.
  • RDF

    RDF stands for Resource Description Framework used for describing Web resources like title, author, content etc.
  • WSDL

    WSDL stands for Web Services Description Language used for describing web services and how to access them.
  • EXCEL

    Microsoft Excel is spreadsheet software developed by Microsoft Corporation used to manipulate numeric data in rows and columns.
  • DHTML

    DHTML stands for Dynamic Hypertext markup language, used on Web to develop Dynamic and intractive web pages.
  • DTD

    DTD stands for Document type definition, is a set of markup declarations that define a document type for an SGML language.
  • E4X

    E4X means ECMAScript For XML, It is a standard extension to ECMAScript So in real life E4X means JavaScript for XML.
