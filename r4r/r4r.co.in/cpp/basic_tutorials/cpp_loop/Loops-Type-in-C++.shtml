Loop Types In C++:-

1. For Loop
2. While Loop
3. Do while loop
4. Nested loop

 

 

1. For loop:-

        For loop in c++ is used to repeat statement continuously  for a specific number of time.

Examples-

#include<iostream>
using namespace std;

int main()
{
int i;

for (i = 0; i < 20; i++)
{
cout << "Hello" << "\n";
cout << "There" << "\n";
}
return 0;
}

2. While Loop-

In While loop  repeat statement until a certain condition is met.  That Means we use While if you dont know how many

times a loop must run.

 

Examples:-

#include<iostream>
using namespace std;

{
int i=0;

while (i < 4)
 {
cout << i++;

  }
}

3. Do- while Loop:-

Do while Loop is basically similar to while loop. The do-while loop is usually preferred over a while-loop when the statement needs to be executed at least once

do
{
do something;
}
while (expression);

Do something first and then test if we have to continue. The result is that the loop always runs once.

 

Example:-

#include <iostream>

using namespace std;

int main()
{
int x;

x = 2;
do {
cout<<"Hello, world!\n";
} while ( x != 2 );
cin.get();
}
