Loop Control Statement In C++

 

Control statement is a way For a programmer to control What pieces of  the program are to be executed at certain times.

It is use for change Execution from its normal sequence.

 

There are types of control statement :-

1. Break statement

2. Continue Statement

3. Go to Statement

 

Break statement-    When we use of Break statement in our programming then it terminates the

 loop and switch Statement and transfer execution to the statement immediately following loop.

Examples:-

#include <iostream>
using namespace std;

int main ()
{
                              // Local variable declaration:

int a = 20;

                              // do loop execution
do
{
cout << "value of a: " << a << end1;
a = a - 1;
if( a < 15)
{

break;                    // terminate the loop
}
}while( a < 10 );

return 0;
}

Output:-

20

19

18

17

16

15

Continue Statement:-   

Continue statement is use for if  sometimes necessary to skip some statement/s inside the loop. In that case, continue

Statement continue forces the next iteration of the loop to take place, skipping any code in between.

Example:-

#include <iostream>
using namespace std;

int main ()
{
int a = 20;

do
{
if( a == 25)
{
// skip the iteration.
a = a + 1;
continue;
}
cout << "value of a: " << a << endl;
a = a + 1;
}while( a < 30 );

return 0;
}

Goto Statement:-   In C++ programming Goto statement is used for an unconditional jump. If we want jump to a labeled statement  then we use of Goto statement to jump to another spot in the code.

 

Example-

#include <iostream>
using namespace std;

int main ()
{
// Local variable declaration:
int b = 20;

// do loop execution
LOOP:do
{
if( b == 25)
{
// skip the iteration.
b = b + 1;
goto LOOP;
}
cout << "value of b: " << b << endl;
b = b + 1;
}while( a < 20 );

return 0;
}
