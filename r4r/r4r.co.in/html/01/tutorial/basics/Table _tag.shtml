TABLES TAG

The <tables> tag

tables are defined with <table>tag

there are some sub tags under table tag

      <tr> table row tag as tables are divided into rows  and columns.

      each raw is divided into data cells .data cells tag is <td>which holds the content of data cells

     <td>tag contains links , images ,lists, forms and other tables

     <th> tag information on table header define with <th> tag

<table border="1">
<tr>
<th>Header 1</th>
<th>Header 2</th>
</tr>
<tr>
<td>row 1, cell 1</td>
<td>row 1, cell 2</td>
</tr>
<tr>
<td>row 2, cell 1</td>
<td>row 2, cell 2</td>
</tr>
</table>
