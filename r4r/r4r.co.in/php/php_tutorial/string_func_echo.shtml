echo()

echo() function output one or more strings.

Syntax: 
echo(strings);

Example1:

<?php 
echo "Hello world..!!"; 
?>

Output:

Hello world..!!

Example2:

<?php
$str = "Gud Morning..!!";
echo $str;
echo "<br>Have a nice day!!!";
?>

Output: 

Gud Morning..!!
Have a nice day!!!
