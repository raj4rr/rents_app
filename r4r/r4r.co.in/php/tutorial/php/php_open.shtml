Some different ways to open a file

The PHP requires you to specify your intentions when you open a file. Mainly three type basic ways to open a file and the corresponding character that PHP uses.
Read: 'r'
Open a file for read only use. The file pointer begins at the front of the file.
Write: 'w'
Open a file for write only use. In addition, the data in the file is erased and you will begin writing data at the beginning of the file. This is also called truncating a file, which we will talk about more in a later lesson. The file pointer begins at the start of the file.
Append: 'a'

Open a file for write only use. However, the data in the file is preserved and you begin will writing data at the end of the file. The file pointer begins at the end of the file.



In PHP the file pointer is a way of remembering its location in a file. if When you open a file for reading, the file pointer begins at the start of the file. and that's making sense because you will usually be reading data from the front of the file.
However, when we open a file for appending, the file pointer is at the end of the file, and we most likely will be appending data at the end of the file. When use reading or writing functions they begin at the location specified by the file pointer.

Explanation for fopen in different ways

Mostly there are three basic ways to open a file have distinct purposes. If we want to get information out of a file, like search an e-book for the occurrences of "cheese", then you would open the file for read only.and If we wanted to write a new file, then overwrite an existing file, after we would want to open the file with the "w" option. File Open into advanced
The additional ways using to develop a file open . Above we started the standard ways to open a file. However, we can open a file in such a way that reading and writing is allowable! This combination is done by placing a plus sign "+" after the file mode character.

Read/Write: 'r+'
Opens a file so that it can be read from and written to. The file pointer is at the beginning of the file.

Write/Read: 'w+'
This is exactly the same as r+, except that it deletes all information in the file when the file is opened.

Append: 'a+'
This is exactly the same as r+, except that the file pointer is at the end of the file.
