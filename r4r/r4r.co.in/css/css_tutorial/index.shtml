CSS(cascading style sheet) Tutorial

CSS is an acronym which means Cascading Style Sheets.A style sheet is made up of style rules that tell a browser how to present a document

This technique can save you a lot of work. If you, for example, would like to change the background color of a website with 100 pages, a style sheet can save you from having to manually change all 100 HTML documents.

Using CSS the change can be made in a few seconds just by changing one code in the central style sheet.
