Cursor In CSS
Previous Home Next

The cursor property of CSS allows you to specify the type of cursor that should be displayed to the user. One good usage of this property is in using images for submit buttons on forms. By default, when a cursor hovers over a link, the cursor changed from a pointer to a hand. For a submit button on a form this does not happen. Therefore, using the cursor property to change the cursor to a hand whenever someone hovers over an image that is a submit button. This provides a visual clue that they can click it.

  1. Auto: Shape of the cursor depends on the context area it is over. For example an I over text, a hand over a link, and so on...
    2. .auto{
cursor:auto;
}
  2. crosshair: A crosshair or plus sign
    3. .croshair{
cursor:crosshair;
}
  3. default: An arrow.
    4. .default{
cursor:default;
}
  4. pointer: A pointing hand.
    5. .pointer{
cursor:pointer;
}
  5. Move: The I bar
    6. .move{
cursor:move;
}
  6. E-resize: The cursor indicates that an edge of a box is to be moved right (east)
    7. .e-resize{
cursor:e-resize;
}
  7. ne-resize: The cursor indicates that an edge of a box is to be moved up and right (north/east).
    8. .ne-resize{
cursor:ne-resize;
}
  8. nw-resize: The cursor indicates that an edge of a box is to be moved up and left (north/west).
    9. .nw-resize{
cursor:nw-resize;
}
  9. n-resize: The cursor indicates that an edge of a box is to be moved up (north).
    10. .n-resize{
cursor:n-resize;
}
  10. se-resize: The cursor indicates that an edge of a box is to be moved down and right (south/east).
    11. .se-resize{
cursor:se-resize;
}
  11. sw-resize: The cursor indicates that an edge of a box is to be moved down and left (south/west).
    12. .sw-resize{
cursor:sw-resize;
}
  12. s-resize: The cursor indicates that an edge of a box is to be moved down (south).
    13. .s-resize{
cursor:s-resize;
}
  13. w-resize: The cursor indicates that an edge of a box is to be moved left (west).
    14. .w-resize{
cursor:w-resize;
}
  14. Text: The I bar
    15. .text{
cursor:text;
}
  15. Wait: An hour glass
    16. .wait{
cursor:wait;
}
  16. Help: A question mark or balloon, ideal for use over help buttons.
    17. .help{
cursor:help;
}
