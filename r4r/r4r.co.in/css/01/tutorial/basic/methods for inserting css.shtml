Methods for inserting CSS Style sheet
Previous Home Next

There are three ways of inserting a style sheet:

1.External Style Sheet

An external style sheet is applied to many pages. With an external style sheet, you can change the look of an entire Web site by changing one file. You have to make sure that each page must link to the style sheet using the <link> tag. The <link> tag goes inside the head section:

<head>
<link rel="stylesheet" type="text/css" href="myweb.css" />
</head>

2.Internal Style Sheet

An internal style sheet should be used for a single document has a unique style. You define internal styles in the head section of an HTML page, by using the <style> tag, like given below-

<head>
<style type="text/css">
hr {color:sienna;}
p {margin-left:20px;}
body {background-image:url("images/same.gif");}
</style>
</head>

3.Inline Styles

An inline style loses many of the advantages of style sheets by mixing content with presentation. To use inline styles you use the style attribute in the relevant tag.The style attribute can contain any CSS property.

<p style="color:sienna;margin-left:20px">This is a paragraph.</p>
