Hiding Date and Time in DateTimePicker control-

  Datetime Picker control contains no property that will allow you to hide the current date, nor to set the value of the control to null or an empty string, it is still possible. In this application you can make this possible to hide date and time in DateTime picker control.

                 

Code for this is given below- 


public Form1()
        {
            InitializeComponent();

            if (mDday == Convert.ToDateTime("02/01/2011"))
            {
                dateTimePicker1.Value = mDday;
                txtDate.Hide();
            }
        }
___________________________________________________________________________________________________________________

private void dateTimePicker1_ValueChanged(object sender, EventArgs e)
        {
            txtDate.Hide();
            mDday = dateTimePicker1.Value;
        }
