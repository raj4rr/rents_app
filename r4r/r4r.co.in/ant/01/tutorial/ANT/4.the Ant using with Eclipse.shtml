You Working From Eclipse then you Using JAR file to attach the Eclipse.

Firstly go to :
  1. Open Eclipse.
  2. Create workspace.
  3. To add jar files in library file.
  4. Go to Window menu select Preference.
  5. And then choose the Ant.
  6. Then Open new window.
  7. Select Ant Home.
  8. After that go to Add External Files for jar.
  9. Select Jar files and attach Ant Home.
  10. And finally Apply then Ok.
